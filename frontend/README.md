# 혼디가개 Frontend

혼디가개 웹 프론트엔드 워크스페이스.

## 예정 스택

- Next.js (App Router) + TypeScript
- 카카오 지도 API — 위치 기반 관광지 시각화, 경로 안내
- 카카오 로그인 연동

## 주요 화면 (기획 — AI 기능 선정 결과에 따라 확정)

AI 기능은 후보 풀에서 몇 개만 선정해 개발한다 (루트 `README.md` 참고). 아래는 후보 기능 전체 기준의 화면 초안이며, 선정에서 제외된 기능의 화면은 만들지 않는다.

- 여행 조건 입력 (일정, 반려견 프로필, 예산) → AI 여행 플래너
- 생성된 일정 타임라인 + 지도 뷰
- AI 여행 비서 채팅 (여행 중 실시간 일정 변경)
- 여행 적합도 분석 카드 (점수 + 추천 이유, XAI)
- 반려견 프로필 / 성향 리포트
- 여행 후기 자동 작성 + SNS 공유
- 긴급 상황 도우미 (24시 동물병원 안내)

## 백엔드 연동

- API 계약과 공통 응답 규약은 [backend/docs](../backend/docs/README.md) 기준을 따른다.
- 공통 응답 래퍼는 `Response<T>` (`dataHeader` / `dataBody`) 구조다.
