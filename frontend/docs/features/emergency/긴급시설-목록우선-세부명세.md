# 긴급 시설 목록 우선 · 위치 주 버튼 세부 명세

> 진단 근거: [`docs/superpowers/specs/2026-09-15-ui-ux-audit-design.md`](../../superpowers/specs/2026-09-15-ui-ux-audit-design.md) **E-1 (P0) · E-2 (P0)**, 시안 §3 ① ②.
> `공통명세.md`(E0~E8) 가 이 화면의 정본이다. 이 문서는 **기본 보기** 와 **위치 폴백 UI** 두 가지만 바꾼다. 지도 클러스터 마커 교체(E-1 후반) · 필터 순서(E-3) · 영업시간 한 줄(E-4)은 **범위 밖** — D8 참고.

## D0. 화면 정의

- **경로**: `/emergency`. 인증 불필요 (변경 없음).
- **현상 (2026-09-15 실측, 390px)**: 기본 보기가 지도라 첫 화면이 `이 지역 42곳 · 14곳 · 21곳 · 8곳 …` 알약이 겹친 지도다. 위치 권한이 없으면 목록 위에 `위치 권한이 없어 거리를 계산할 수 없어요.` 와 `현재 위치로 다시 찾기` secondary 버튼이 서는데, 응급 화면에서 가장 급한 행동이 가장 낮은 위계다.
- **바꾸는 것**
  1. **E-1** `EMERGENCY_DEFAULT_VIEW` 를 `'map'` → `'list'`. 지도는 카드 제목 줄 `ViewToggle` 로 한 탭.
  2. **E-2** 위치 폴백 UI 를 카드 **머리(고정 영역)** 로 올리고, `내 위치로 가까운 병원 찾기` **primary** 버튼 + 권역 세그먼트(`제주시 · 서귀포 · 동부 · 서부`) 로 바꾼다. 세그먼트는 기존 `researchAt(center)` 로 기준점을 옮긴다.
- **바꾸지 않는 것**: 필터 축·칩·레일 · `FacilityRow` · 지도 갈래 내부 · `useNearbyFacilities` · 반경 · 0건 두 갈래 · E5 "실패해도 화면이 비지 않는다"(제주 중심 폴백 조회는 그대로 먼저 돈다).

## D1. 레이아웃

목록 갈래(3층 표면, E0). 우측 카드 `Surface fill` 의 **머리**가 늘어난다.

```text
[Surface 머리 — 고정]
  병원 · 약국                                      [목록|지도]      (제목 · ViewToggle — 변경 없음)
  제주 214곳 · 지금 진료중 100곳                                   (부제 — 신규, E2-1 totalCount 기준)
  ┌ 위치 폴백일 때만 ─────────────────────────────────────────┐
  │ [ 내 위치로 가까운 병원 찾기 ]  (primary, 전폭, 44px)       │
  │ 위치를 켤 수 없으면 지역을 골라 주세요                       │
  │ (제주시) (서귀포) (동부) (서부)   ← 세그먼트 칩, 44px 탭    │
  └───────────────────────────────────────────────────────────┘
  [필터 칩 줄 — 변경 없음]
  가까운 순 · 반경 10km · {기준} 기준                            (요약 줄 — 기준 문구 갱신)
[Surface 본문 — 구른다]
  행 · 행 · 행 …
```

- 모바일(<768) 칩은 카드 밖(E0 규칙) — 위치 블록은 **카드 안 머리**다. 칩은 좁히는 도구지만 위치 블록은 "무엇을 기준으로 찾을지" 라 결과의 전제이고, 카드가 결과를 담으므로 그 머리에 든다.
- 데스크톱(≥1024) 목록 갈래는 좌 280 레일 / 우 카드. 위치 블록은 우 카드 머리 그대로 (레일에 두지 않는다 — 레일은 필터).
- 위치 블록 높이는 폴백일 때 약 140px. 첫 화면(844) 안에 첫 행 2개가 남는다 (실측 D7).

## D3. 데이터 흐름

### D3-1. 기준점 결정 (변경)

```text
anchor = searchCenter                       ← 지도 재검색 ('map')          (현행)
       ?? regionCenter                      ← 권역 세그먼트 ('region')     (신규)
       ?? position(granted)                 ← 현재 위치 ('current')        (현행)
       ?? JEJU_QUERY_CENTER (fallback)      ← 제주 중심 ('jeju')           (현행)
basis: 'map' | 'region' | 'current' | 'jeju'
showDistance: basis !== 'jeju'              ← 'region' 은 거리를 보여 준다 (기준점이 명시적이다)
```

- 권역을 고르면 `regionCode` 를 상태에 두고 `searchCenter` 는 비운다(둘이 동시에 있으면 지도 재검색이 이긴다 — 지도에서 돌아왔을 때 사용자가 마지막에 한 행동이 지도다).
- `내 위치로 가까운 병원 찾기` 는 기존 `board.locate` 를 부른다. 성공(`granted`)하면 `regionCode` 를 비워 `'current'` 로 돌아간다. 실패하면 폴백 블록이 그대로 남고 버튼 라벨은 바뀌지 않는다 — 브라우저가 권한을 영구 거부한 경우 "다시 찾기" 를 눌러도 프롬프트가 안 뜨는데, 그 사실은 아래 안내 문장(D4 `positionDeniedHint`)이 말한다.
- **좌표는 URL 에 두지 않는다** (현행 `useEmergencyBoard` 머리주석). `regionCode` 도 URL 에 두지 않는다 — 기준점은 필터가 아니라 세션 맥락이다. 공유 URL 은 제주 중심으로 열린다.

## D6. 접근성

- primary 버튼은 `Button` 44px. 폴백 블록의 첫 줄(`positionDenied`)은 `role="status"` 로 두어 위치 실패가 확정되는 순간 한 번 읽힌다. 현행 `PositionNotice` 에 없던 것이다 — 급한 화면에서 "왜 거리가 없나" 를 눈으로 찾게 하지 않는다.
- 세그먼트는 `ChipGroup`(기존 필터 칩과 같은 컴포넌트) · `aria-pressed`. 키보드 좌우 이동은 칩 그룹 현행 규약.
- 보기 토글 기본값이 목록이 되어 스크린리더 사용자의 첫 화면이 목록(읽을 수 있는 구조)이 된다 — 지도 기본은 캔버스가 첫 콘텐츠였다.

## D7. 테스트 케이스

- 순수 로직:
  - `parseViewMode({}, EMERGENCY_DEFAULT_VIEW)` → `'list'`; `viewModeHref('/emergency', '', 'map', EMERGENCY_DEFAULT_VIEW)` → `/emergency?view=map`; `'list'` → `/emergency` (`view-mode.test.ts` 갱신)
  - `useEmergencyBoard` 기준점 우선순위: `searchCenter > regionCenter > granted > jeju` (훅 순수 부분을 함수로 뽑아 `resolveAnchor()` 테스트)
  - `JEJU_REGION_CENTERS.JEJU_CITY === JEJU_QUERY_CENTER` (같은 객체 참조)
- 렌더 분기 (`position-fallback-head.test.ts`, `renderToStaticMarkup`):
  - `denied` → primary 클래스 버튼 1개 · `positionDeniedHint` · 세그먼트 4개
  - `unsupported` · `outside` → 버튼 0개 · 세그먼트 4개
  - `granted` → 컴포넌트가 `null`
- e2e (`e2e/emergency-search.spec.ts` 확장, 권한 거부 컨텍스트 · 390px):
  - `/emergency` 첫 화면에 지도 캔버스가 없고 `병원 · 약국` 카드 제목이 보인다
  - `내 위치로 가까운 병원 찾기` 버튼이 `scrollY=0` 에서 보이고 높이 ≥ 44
  - `서귀포` 세그먼트 클릭 → 요약 줄에 `서귀포 기준`, 첫 행 거리 표시 있음
  - 첫 화면(844) 안에 `FacilityRow` 가 2개 이상 보인다
- 기존 e2e `protected-routes` · `surface` 스펙이 `/emergency` 기본 보기를 지도로 가정한 곳이 있으면 고친다 (grep `view=list`).
- 문구: `message-tone.test.ts`.

## D8. 미결 사항

- **D8-1. 지도 클러스터 알약 → 숫자 원형 마커 (E-1 후반)** — **#655 에서 닫혔다. 규격은 아래 D10 이 정본이다.** (이 문서 머리의 "범위 밖" 문장은 #639 당시 기준이다.)
- **D8-2. 데스크톱도 목록 기본인가** — 선택지 A: 폭 무관 목록 기본(URL 의미가 하나). 선택지 B: 데스크톱만 지도 기본. **추천 A.** `view` 는 URL 파라미터라 폭에 따라 기본값이 갈리면 같은 링크가 기기마다 다른 화면을 연다. 데스크톱 지도(400 부동 패널)는 잘 만들어져 있고 한 탭 거리다.
- **D8-3. 권역 세그먼트를 홈 권역 날씨의 5권역(한라산권 포함)과 맞출까** — 한라산권에는 병원이 없다. **4권역으로 확정.**
- **D8-4. `regionCode` 를 URL 에 둘까** — 두지 않는다 (D3-1). 공유 URL 이 남의 위치 맥락을 실어 나르지 않는다.

### D10-1. 무엇을 바꾸나

| 모양        | `--radius-full` · `1px solid --border-strong` · `--bg` · `--shadow-md` | 알약이 쓰던 토큰 그대로. **새 색을 만들지 않는다**                                       |
| 글자        | `--fg` · 12px · 700 · `tabular-nums` · `letter-spacing: -0.04em`       | 12px 는 `DESIGN.md` §10 의 최소 글자다. 그 아래로 내리지 않는다                          |
| 좌표 기준   | `yAnchor: 0.5` (핀은 `1` 유지)                                         | 원에는 가리킬 뾰족한 끝이 없다. `1` 이면 원이 좌표 위로 통째로 떠서 이웃과 어긋나 보인다 |
| 접근성 이름 | `aria-label` = `messages.map.clusterCount` (`이 지역 {n}곳`)           | 원 안에는 숫자만 남는다. 이름까지 `42` 가 되면 무엇이 42인지 알 수 없다                  |

### D10-3. 자릿수 규칙 (`clusterMarkerText`)

- `1`~`999` 는 **그대로** 쓴다 — `3` · `42` · `135`.
- `1000` 이상은 `999+` 로 접는다. **원을 키우지 않는다** — 원이 늘어나는 유일한 경로를 막는 규칙이다.
- `NaN` · 음수 · 소수는 `0` · `0` · 버림으로 떨어뜨린다. 빈 원이 뜨면 그것이야말로 소음이다.
- `aria-label` 은 **접지 않은 실제 개수**를 말한다 (`999+` 마커도 이름은 `이 지역 1200곳`).

390px 실측(글자 잉크 폭 / 안쪽 30px 대비 좌우 여백): `3` 7.4 / 11.3 · `42` 14.8 / 7.6 · `135` 22.1 / 3.9 · `999+` 29.5 / 0.25. **네 글자는 원을 꽉 채운다** — 조임을 `-0.08em` 까지 내려도 좌우 1.2px 밖에 못 벌어진다. 한 셀에 1000곳 이상이 묶여야 나오는 값이고 긴급 시설 전체가 135곳이라, 원을 키우는 대신 이 꽉 참을 택했다.

### D10-4. 겹침 — 남는 부분이 있다

**격자 셀 간격이 마커 지름보다 좁아지는 확대 단계가 있다.** `cellSizeFor(level)` 과 `metersPerPixel(level)` 로 환산한 인접 셀 중심 간격(제주 위도 33.4°, 경도 방향이 좁다):

| level | 셀(도) | 위도 방향 px | 경도 방향 px |
| ----: | -----: | -----------: | -----------: |
|     6 |  0.004 |         55.7 |         46.5 |
|     8 |  0.012 |         41.7 |         34.9 |
| **9** |  0.040 |     **69.6** |     **58.1** |
|    10 |  0.040 |         34.8 |         29.0 |
|    12 |  0.120 |         26.1 |         21.8 |
|    13 |  0.120 |         13.0 |         10.9 |

`JEJU_MAP_LEVEL` 이 9 이고 반경 10km · 390px 카메라도 `levelForSpanMeters(20000, 390)` → **9** 다. 즉 **실제 첫 화면은 간격이 넉넉한 단계**다.

390px · 레벨 9 간격에 진단이 찍은 일곱 묶음(`42 14 21 8 4 7 5`)을 놓고 `getBoundingClientRect()` 쌍별 겹침을 센 결과:

| 셀 평균의 치우침 | 알약(이전) |   원형(현재) |
| ---------------- | ---------: | -----------: |
| 없음 (셀 중앙)   |    **4쌍** |      **0쌍** |
| ±25%             |        3쌍 |  1쌍 (3.0px) |
| ±40%             |        3쌍 | 1쌍 (20.4px) |

- 묶음 중심은 셀 중앙이 아니라 **실제 좌표의 평균**이라(바다 한가운데를 피하려는 결정, `cluster.ts`) 이웃한 두 평균이 공유 모서리 쪽으로 함께 쏠리면 원끼리도 닿는다. **겹침이 0 이 되지는 않는다.**
- 레벨 10 이상으로 축소하면 **인접 셀 간격 자체가 32 미만**이라 평균이 어디 있든 닿는다.
- **후속 후보**: `cellSizeFor` 를 도(degree) 상수표가 아니라 `metersPerPixel(level)` 기반으로 바꿔 셀을 **화면 픽셀 기준 고정 크기**로 만든다. 그러면 모든 단계에서 간격이 마커 지름을 넘는다. 묶는 규칙 자체가 바뀌어 `/places` 지도까지 영향이 가므로 **이 이슈에서는 하지 않았다.**

### D10-5. 공유 범위

`MapCanvas` 는 `/emergency` 와 `/places`(`place-map-view` · `place-mini-map`)가 함께 쓴다. 클러스터 표현은 **컴포넌트 하나에만 있으므로 두 화면이 같이 바뀐다.** 화면별로 갈라 두 벌을 만들지 않았다 — 같은 컨트롤이 화면마다 다르게 보이는 것이 더 나쁘다(`messages/map.ts` 머리주석의 같은 판단).

### D10-6. 건드리지 않은 것

- **클러스터 클릭 확대는 그대로 얼려 둔다.** `emergency-map-view.tsx` 의 `frozenBounds` doc-comment 가 "알려진 잔존 동작이지 결함이 아니다" 로 못박아 둔 결정이다.
- `clusterByGrid` · `cellSizeFor` · 묶음 중심 계산 · `EMERGENCY_DEFAULT_VIEW`.

### D10-7. 테스트 케이스

- 순수 로직 (`src/lib/map/cluster.test.ts`):
  - `clusterMarkerText`: `3`→`'3'` · `42`→`'42'` · `135`→`'135'` · `999`→`'999'` · `1000`→`'999+'`; 어떤 입력에서도 **길이 ≤ 4**; `NaN`→`'0'` · `-5`→`'0'` · `4.7`→`'4'`
  - `clusterMarkerLabel`: `42`→`이 지역 42곳`, `1200`→`이 지역 1200곳`(접지 않는다), 문구는 `messages.map.clusterCount` 에서 온다
- 브라우저 실측(390): 마커 rect 가 자릿수와 무관하게 `32×32`, 잉크가 원 밖으로 넘치지 않는다(`scrollWidth ≤ clientWidth`).
- **지도 SDK 를 태운 e2e 는 없다.** 카카오 웹 도메인에 등록된 로컬 출처가 `localhost:5174` 하나뿐이라 다른 포트에서는 SDK 가 `AccessDeniedError` 로 떨어지고 화면이 목록 폴백으로 간다 (`errorScript`). 위 실측도 같은 이유로 실제 `globals.css` 를 태운 390px 문서 안에서 마커 DOM 을 직접 놓고 쟀다.
