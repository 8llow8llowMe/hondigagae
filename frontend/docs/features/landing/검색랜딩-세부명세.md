## D0. 화면 정의

- **한 줄 정의**: "제주 애견동반 숙소" 처럼 **사람들이 치는 검색어 하나에 답하는 공개 페이지**. 동반 가능으로
  확인된 장소 목록을 서버에서 그려 크롤러가 끝까지 읽게 한다.
- **왜 필요한가**: `/places` 의 필터는 `<button>` + `router.replace` 라 "숙박 · 동반 가능" 조합이 **크롤 가능한 URL 로
  존재하지 않는다.** 목록도 무한 스크롤이라 서버 HTML 에는 첫 20곳뿐이다.
- **경로**: `/jeju/[topic]` · **공개** (`proxy.ts` 매처 밖) · 알 수 없는 `topic` 은 **404**(`notFound()`)

| topic                      | h1                        | 조회 조건                                               | dev 건수(2026-10-03) |
| -------------------------- | ------------------------- | ------------------------------------------------------- | -------------------- |
| `pet-friendly-stays`       | 제주 애견동반 숙소        | `contentType=LODGING` · `petAllowanceType=ALLOWED`      | 56                   |
| `pet-friendly-places`      | 제주 강아지랑 가볼만한 곳 | `contentType=TOURIST_SPOT` · `petAllowanceType=ALLOWED` | 73                   |
| `pet-friendly-restaurants` | 제주 애견동반 식당·카페   | `contentType=RESTAURANT` · `petAllowanceType=ALLOWED`   | 126                  |

- **`ALLOWED` 만 싣는다.** API 의 `petAllowanceType` 은 값 하나만 받고, `PARTIALLY_ALLOWED` 를 섞으려면 두 커서를
  합쳐야 한다. "애견동반" 검색어에 가장 분명한 답이 `ALLOWED` 다.
- **범위 밖**: 권역별(애월·성산) 랜딩 — 시군구 코드가 행정시 둘뿐이라 읍면 단위로 나눌 조건이 API 에 없다. 쇼핑(동반 가능
  276곳)은 검색 의도가 약해 뺐다.

## D3. 데이터 흐름

- `GET /api/v1/places?areaCode=39&contentType=…&petAllowanceType=ALLOWED&size=50[&lastPlaceId=…]` — 공개 API
- **서버 렌더만 한다. `HydrationBoundary` 를 쓰지 않는다** — 이 화면에는 데이터를 다시 읽는 클라이언트 컴포넌트가 없다
  (`PlaceRow` 는 서버 컴포넌트). §9 결정 트리의 "서버 프리페치" 가 아니라 서버가 곧 화면이다.
- **페이지는 커서 링크다** — `?after={마지막 placeId}`. 무한 스크롤이 아니라 `<a href>` 라 크롤러가 끝까지 따라간다.
  `after` 는 `isPlaceId` 로 검사하고 아니면 첫 페이지로 본다.
- canonical: 첫 페이지는 `/jeju/{topic}`, 다음 페이지는 `?after=` 를 포함한 자기 주소(페이지마다 다른 장소다).

## D4. 상호작용

링크뿐이다. 행 → 장소 상세, `다음 장소 더 보기 ›` → `?after=`, `처음부터 보기` → 첫 페이지.

## D8. 미결 사항

- **`PARTIALLY_ALLOWED` 포함 여부** — 관광지는 22곳이 더 있다. 선택지: (A) 지금처럼 `ALLOWED` 만, (B) 두 커서를 이어 붙인다.
  **추천 A** — 페이지 링크가 커서 하나로 단순하고, 부분 동반은 상세에서 조건을 읽어야 해서 "애견동반" 검색어의 답으로 약하다.
- **모바일 진입점** — 푸터는 768 미만에서 감춰진다. 모바일 내부 링크는 랜딩끼리 · 사이트맵에 기댄다.
