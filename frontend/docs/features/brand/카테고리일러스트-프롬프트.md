> 상태: **v2 적용** (2026-09-29) — 풍경 SVG 여섯 장을 캐릭터 그림체의 정물 WebP 로 바꿨고(#1032),
> 자산이 없던 나머지 4종(축제 · 코스 · 레포츠 · 쇼핑)을 더해 스펙의 8종을 전부 덮는다.
> v1(2026-09-04, 실크스크린 풍경 초안)은 git 히스토리에 있다.

사진이 없는 장소 · 일정 항목의 타일(`lib/place/illustration.ts` · `lib/plan/illustration.ts`)을
채우는 그림이다. 이 문서는 **그 그림을 다시 뽑을 때 쓰는 프롬프트와 후처리의 정본**이다.

## v1 에서 바꾼 것과 이유

- **풍경 → 반려견 물건 정물.** 산 · 집 · 길은 어느 여행 앱에 넣어도 되는 그림이었다.
  타일은 64~96 정사각이라 넓은 풍경보다 물건 하나의 실루엣이 읽힌다.
- **캐릭터는 넣지 않는다.** 목록 · 일정 타임라인은 DESIGN.md §0-5 "들이지 않는 곳"이다.
  대신 밥그릇 · 목줄 · 방석 같은 **흔적**으로 "반려견과 가는 곳" 을 말한다.
- **그림체는 캐릭터(`illustrations/about/*.svg`)를 따른다.** 외곽선 · 그라데이션 없이 가위로
  오린 듯한 면, 같은 계열 한 톤으로만 음영.
- **SVG → WebP.** 디테일이 늘어 벡터로 다시 따지 않았다. 그레인은 생성 도구에 맡기지 않고
  후처리로 구워 넣는다 — 장마다 세기가 달라지기 때문이다.

## 뽑는 법

1. 캐릭터 두 장(`dog-leash` · `dog-sit-front`)을 **스타일 참조로 첨부**한다.
2. 아래 장면 프롬프트를 통째로 붙인다. 공통 스타일은 각 프롬프트에 이미 들어 있다.
3. 도구가 워터마크(Gemini 의 ✦ 등)를 붙이면 지운다. 프롬프트로는 안 없어진다.
4. 64 · 96 으로 줄여 보고 주제가 읽히는지 확인한다. 흔한 실패 셋 — 물건이 작다 · 바닥 띠가
   화면 끝에 안 닿는다 · 크게 칠한 검정이 덩어리로 보인다.
5. [후처리](#후처리--그레인--webp)로 그레인을 입혀 `public/illustrations/` 에 넣는다.

**네거티브** (지원하는 도구에서만)

```text
outline, line art, stroke, gradient, drop shadow, glossy, 3D render, photo, realistic, noise texture, grain, text, letters, watermark, sparkle icon, busy background, tiny objects, floating ground, people, dog, cat, neon, oversaturated colors
```

## 후처리 — 그레인 · WebP

v1 SVG 의 그레인(`feTurbulence baseFrequency="0.85"` · `viewBox 100` · 알파 0.18 × 불투명도 0.7)을
1024 로 렌더해 잰 값에 맞춘다 — **평평한 면의 표준편차 약 1.3(0~~255), 알갱이 8~~16px.**
옥타브 주기를 이미지 폭에 비례(12 · 6 · 3 · 1.5px)로 두므로 SVG 처럼 표시 크기와 함께 줄고 커진다.

- 입력은 **1024 정사각**이어야 한다. 사진 0장인 장소 상세에서 660 까지 커진다.
- 색 평균을 옮기지 않는다(평균 보존). 팔레트는 생성 단계에서 이미 정해졌다.
- WebP 품질 90. 95 로 올리면 가장 고운 옥타브가 조금 더 남지만 파일이 35% 커진다.

```python
# python3 grain.py 원본.png=public/illustrations/place-lodging.webp ...  (Pillow 필요)
import sys
from PIL import Image, ImageChops, ImageStat

SIZE, TARGET_STD = 1024, 1.3

def octave(period):
    small = max(2, round(SIZE / period))
    return Image.effect_noise((small, small), 64).resize((SIZE, SIZE), Image.BICUBIC)

layers = [octave(p) for p in (12, 6, 3, 1.5)]
weights = [1, 0.5, 0.25, 0.125]
acc, total = layers[0], weights[0]
for layer, w in zip(layers[1:], weights[1:]):
    total += w
    acc = Image.blend(acc, layer, w / total)
mean, std = ImageStat.Stat(acc).mean[0], ImageStat.Stat(acc).stddev[0]
k = TARGET_STD / std
pos = Image.merge("RGB", [acc.point(lambda v: max(0, round((v - mean) * k)))] * 3)
neg = Image.merge("RGB", [acc.point(lambda v: max(0, round((mean - v) * k)))] * 3)

for src, dst in (arg.split("=") for arg in sys.argv[1:]):
    im = Image.open(src).convert("RGB")
    assert im.size == (SIZE, SIZE), (src, im.size)
    ImageChops.subtract(ImageChops.add(im, pos), neg).save(dst, "WEBP", quality=90, method=6)
```
