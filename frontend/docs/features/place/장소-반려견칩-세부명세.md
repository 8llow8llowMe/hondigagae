### D7-7. 남는 위험

- **`:has()` 미지원 브라우저** — 지도 보기에서도 띠 헤더가 남는다(#1287 D5 전제). 그때는 헤더 스위처와 칩이 한 화면에 둘이다. 같은 스토어라 값은 어긋나지 않고, 대상 브라우저 밖이라 받아들인다.
- **체구 필터 URL 맞춤은 동작 변경이다** — 지금은 바꿔도 결과가 그대로다. 띠 헤더 스위처 · 담기에서 바꾼 경우에도 URL 이 바뀐다(`replace`, 히스토리 무증가). 사용자 승인됨(D8-3).
- **위/아래 재기의 실제 자리는 node 테스트로 못 잡는다** — 판정만 순수 함수로 잠그고, 자리는 D7-6 실측이 맡는다.
- **메뉴가 `overflow-hidden` 조상에 잘릴 수 있다** — 도킹 패널(`map-panel-width … overflow-hidden`)은 폭 400 · 전고라 `start-0` 160 패널이 안에 들지만, 칩 자리를 옮기면 다시 본다.
- **`PlaceFilterPetSync` 가 한 화면에 둘 마운트되면** 같은 `replace` 가 두 번 나간다(결과는 같다). 보기 분기 안에 하나만 둔다 — 소스 단언으로 잠근다.
- **하이드레이션 깜빡임** — 서버는 첫 반려견, 복원 뒤 저장 반려견. 칩 폭이 이름 길이만큼 한 번 바뀐다(헤더와 같은 기존 동작).
- **칩은 e2e 공백이다** — 지도 보기 전체가 e2e 공백인 것과 같은 이유(#1287 D7-5).

| **B. 지도 보기에만 — 목록은 헤더 (결정)** | #1065 원칙 그대로 — 바꾸는 곳이 화면마다 하나다. 목록 보기 파일 무변화 | 보기를 오가면 바꾸는 자리가 헤더 ↔ 필터 줄로 옮긴다            |
| C. 목록 보기에서만 헤더 스위처를 숨긴다   | 판정 맥락 옆에 남는다                                                  | 셸에 라우트 분기가 들어간다                                    |

**결정: B.** 실측(D0-1)으로 지도 보기는 모든 폭에서 헤더 스위처가 없으므로 "칩 = 아일랜드일 때만"(`petSwitch={island}`) 하나로 한 화면에 하나가 지켜진다. 알약 쪽을 뺄 것은 없다.

### D8-2. 미리보기가 목록 자리를 가릴 때 칩이 안 보인다 — **닫음: 권고 A**

<1024 는 미리보기가 열리면 목록 시트가 `hidden`, 1024–1279 는 목록 칸이 `invisible` 이다 — 판정을 보는 동안 칩이 없다.
칩이 지도 보기의 **유일한** 바꾸는 곳이 된 만큼 다시 판단했다.

| 안                                                        | 장점                                                                 | 단점                                                                                       |
| --------------------------------------------------------- | -------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| **A. 그대로 (권고)**                                      | 판정 카드 · 미리보기 머리 무변화. ≥1280 은 칩과 판정이 나란히 보인다 | 그 폭에서는 `‹ 목록`(또는 ✕) → 칩 → 장소 다시 고르기, 세 번 누른다                         |
| B. 판정 카드 머리 `오늘 몽실이와` 를 스위처 트리거로(`▾`) | 판정 바로 위에서 바꾼다                                              | 같은 화면에 바꾸는 곳 둘(≥1280 칩과 함께 보인다) — 방금 D8-1 에서 피한 모양. 헤드라인 위계 |
| C. 미리보기 머리 줄에 칩 하나 더                          | 자리가 있다                                                          | B 와 같은 중복 + 1024 `‹ 목록` 비킴 자리와 부딪힌다                                        |

**권고 A 로 닫는다.** B · C 는 D8-1 이 고른 "한 화면에 하나" 를 ≥1280 에서 깬다. 판정 기준을 자주 바꾸는 행동은 "여러 장소를 같은
반려견으로 훑기" 의 앞단에서 한 번 일어나는 것이 보통이라, 목록 단계(칩이 보이는 상태)에서 바꾸고 고르는 순서가 자연스럽다.
실사용에서 "미리보기를 보다 바꾸러 돌아간다" 가 잦다는 근거가 생기면 그때 B 를 별 이슈로 낸다.
