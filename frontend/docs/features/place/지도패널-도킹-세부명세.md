# 장소 찾기 지도 — 도킹 패널 세부 명세

> 상태: **구현 완료** (#1232 — PR #1256 `/places` · 담기, PR #1260 긴급 시설, 2026-10-08) — 계획 `docs/superpowers/plans/2026-10-08-map-docked-panels.md`.
> **범위 확정(2026-10-07 사용자 결정)**: `/places` · 담기 지도 · 긴급 시설 지도 세 화면. 패널 폭 400 유지, 손잡이는 스택 전체를 접는다 (D8).
> 상위: `공통명세.md` S1 "장소 찾기 — 보기 전환과 필터" · `지도미리보기-세부명세.md`(#1227 · #1230).
> 참고 화면: 네이버 지도 데스크톱 — 목록 · 상세 패널이 화면 왼쪽에 붙고, 손잡이가 가장 오른쪽 패널의 세로 중앙에 있다.

## D0. 화면 정의

- **경로**: `lg`(1024) 이상의 지도 보기 세 화면 — `/places`(D2~D7), 담기 지도 `/plans/.../add`(D9), 긴급 시설 `/emergency`(D10).
  모바일 · 태블릿(하단 시트)은 바꾸지 않는다.
- **왜**: 지금 목록 · 미리보기 패널은 지도 위에 **떠 있는 카드**다 — 사방 여백(좌 16 · 위 24 · 아래 32), 둥근 모서리,
  패널 사이 간격(접기 탭 24 + 12). 사용자 지적: 빈 공간이 많아 컴팩트하지 않고, 접기 탭(패널 밖 오른쪽 위)과 펼치기
  버튼(좌상단)이 따로 놀아 손이 두 군데로 간다.
- 세 화면의 패널 모양 · 손잡이 · 축척 자리가 **같아야 한다** — #396 이 재검색 알약을 두 지도 화면에 똑같이 둔 것과 같은 이유다.

## D2. 도킹 배치(to-be)

```text
헤더 ───────────────────────────────────────────────────────────────────────
│ 목록 400        │ 미리보기 400     ▐◀│                            [목록 보기]│
│ 검색            │ ✕                ▐ │                               [◎]  │
│ 필터            │ 사진 캐러셀       ▐ │          지도                       │
│ 목록 20곳       │ 수월봉 [여행 적합]▐ │                                     │
│ ─ 행 ─          │ …                ▐ │      [이 지역에서 재검색]           │
│ ─ 행 ─          │ [로그인][담기]    ▐ │                     축척 ▬▬ kakao  │
───────────────────────────────────────────────────────────────────────────
                                     ↑ 손잡이(가장 오른쪽 패널의 오른쪽 가장자리 세로 중앙)
```

- **목록 패널**: `left 0 · top 0 · bottom 0`(지도 루트 기준 — 헤더 바로 아래부터 화면 바닥까지), 폭 400.
  **`/places` 는 #1287(지도 아일랜드) 뒤로 화면 맨 위(y 0)부터다** — 헤더 띠가 걷히고 스택 맨 위 64 가 **로고 띠**
  (`bg-bg` · 아래 1px 경계)가 된다. 목록 · 미리보기 · 시설 요약 본문은 그 아래 y 64 부터라 패널 안쪽은 움직이지 않는다
  (`지도-아일랜드헤더-세부명세.md` D2-1). 긴급 · 담기(D9 · D10)는 헤더 바로 아래 그대로다.
  **#1300 부터 로고 띠는 목록 칸 폭만이고 목록만 y 64 부터다** — 미리보기 · 시설 요약 칸은 **y 0** 부터 서서 자기 머리
  64(`‹ 목록` · ✕, 로고와 같은 높이)를 갖는다(`지도-아일랜드알약-정리-세부명세.md` D1-2 · D2-1).
  모서리 `rounded-none`, **오른쪽 1px 경계선**(`border-r border-border`). 바깥 여백 0.
- **미리보기(≥1280)**: 목록 바로 옆 `left 400` · `top 0 · bottom 0`, 폭 400. **간격 0** — 목록의 오른쪽 경계선이 둘 사이를 가른다.
  미리보기도 오른쪽 1px 경계선.
- **미리보기(1024~1279)**: 지금처럼 **목록 자리**를 쓴다(`left 0`, 목록은 `lg:max-xl:invisible`). 400 + 400 이면 지도가
  224 남는다.
- **그림자**: 지도와 패널 스택의 경계를 가르는 **오른쪽 그림자 하나**만 스택 바깥에 둔다(패널마다 따로 두지 않는다).
  지도 위에 얹힌 면이라 `token-usage.test.ts` FLOATING 소유자는 그대로 `place-map-view.tsx` 다.
- **지도는 화면 전체 폭 그대로다** — 패널이 지도 위에 얹힌다(지금과 같다). 지도 폭을 줄이면 열고 닫을 때마다 `relayout` →
  `idle` → 재검색 권유가 떠서 #396 · #1143 의 "옮기지 않았는데 흔들리지 않는다" 가 깨진다. 고른 핀은 지금처럼
  `selectedOffset` 이 덮인 폭을 재서 남은 지도 가운데로 보낸다(패널 오른쪽 끝 = 400 또는 800).
- **패널 안쪽은 바꾸지 않는다** — 검색 · 필터 · 목록 · 미리보기 본문 그대로다. 둥근 모서리를 걷으면서 안쪽 첫 줄 위 여백이
  너무 붙어 보이면 `pt` 만 조정한다(실측으로 정한다).

## D3. 접기 · 펼치기 손잡이

- **하나만 둔다.** 지금의 "패널 밖 오른쪽 위 접기 탭" 과 "접힌 뒤 좌상단 펼치기 버튼" 을 걷고, 손잡이 하나가 자리를 옮긴다.
- **자리**: 보이는 가장 오른쪽 패널의 **오른쪽 가장자리, 세로 중앙**(`top: 50%`, 반쯤 걸친 탭).
  - 목록만 열림 → 목록 오른쪽(`x = 400`)
  - 미리보기 열림(≥1280) → 미리보기 오른쪽(`x = 800`)
  - 미리보기 열림(1024~1279) → 미리보기 오른쪽(`x = 400`)
  - 접힘 → 화면 왼쪽 끝(`x = 0`) 세로 중앙, 화살표 방향만 바뀐다(`‹` → `›`)
- **크기**: 보이는 탭 24×48, **누르는 자리 44×48 이상**(`::before` 로 넓힌다 — `ViewToggle` 의 36 → 46 과 같은 수법, DESIGN.md
  44px 하한). 면은 패널과 같은 `bg-bg` · `border-border`, 오른쪽만 둥글다(`rounded-r-md`).
- **접는 대상은 스택 전체**(목록 + 미리보기)다 — 네이버와 같다. 미리보기만 닫는 일은 미리보기 머리의 ✕ 가 한다.
  - 접으면 스택이 왼쪽으로 밀려난다(`translateX(-100%)`, 지금의 슬라이드 · `inert` 규칙 그대로 — #531).
  - 펼치면 접기 전 상태(목록만 / 목록 + 미리보기)로 돌아온다. `?place=` 는 접기와 무관하게 유지된다.
- **접근성**: `<button aria-expanded aria-controls="{스택 id}">`, 이름은 `목록 패널 접기` / `목록 패널 펼치기`(기존 문구 재사용).
  접혀 있는 동안 스택은 `inert`. 손잡이는 스택 **밖**(형제)이라 접혀도 포커스가 닿는다.
- 손잡이가 지도 위 다른 컨트롤과 겹치지 않는다 — 세로 중앙은 지도 위 컨트롤(위: 보기 전환 · 내 위치, 아래: 재검색 · 축척)과 떨어져 있다.

## D5. 카카오 축척 · 로고 우하단

- **이유가 둘이다.** ① 사용자 요청. ② 도킹 패널이 좌하단을 덮으면 **카카오 로고가 가려진다** — 로고는 가리면 안 되는
  표시다(지금은 패널 바닥을 32 띄워 피했다).
- **수단**: SDK `Map#setCopyrightPosition(CopyrightPosition.BOTTOMRIGHT, reversed?)` — 2026-10-07 로드된 SDK 에 메서드와
  `CopyrightPosition.{BOTTOMLEFT,BOTTOMRIGHT}` 가 있는 것을 확인했다. `ScaleControl` 생성자는 없다.
- **실측 결과(2026-10-08)**: 축척 막대가 로고와 **함께** 옮겨진다 — `reversed=false` 면 `축척 ▬▬ kakao` 순서로 로고가 모서리에 선다(1440: 축척 x 1370 · 로고 x 1398, 바닥 같은 줄). 아래 대안은 쓰지 않았다.
- **확인할 것(구현 첫 단계, 끝남)**: 축척 막대가 로고와 **함께** 옮겨지는가. 따로 남으면 축척만 좌하단에 남아 도킹 패널 밑에 깔린다 —
  그때는 축척을 직접 그리거나 숨기는 안을 다시 정한다.
- **어디에 거는가**: `MapCanvas` 에 `copyrightPosition?: 'left' | 'right'` 옵션을 두고, 도킹 패널이 있는 지도만 `right` 를 준다.
  다른 지도(상세 미니맵 · 일정 동선 · 산책 코스)는 기본(좌하단) 그대로다.
- `kakao-maps.d.ts` 에 `setCopyrightPosition` 과 `CopyrightPosition` 타입을 더한다.
- 모바일은 하단 시트가 아래를 덮는 것이 지금과 같다 — 우하단으로 옮겨도 나빠지지 않는다.

## D9. 담기 지도 (`/plans/.../add`, `plan-add-place-view.tsx`)

- 같은 `PlaceMapView` 라 D2~D7 이 그대로 걸린다. 미리보기는 이 화면에서 꺼져 있으므로(`preview` 없음, #1227) 스택은 목록 하나다.
- **떠 있는 머리 카드(일정으로 돌아가기 · 제목 · 일자, #556 · #1012 `head`)를 목록 패널 맨 위 줄로 넣는다.** 지금은 패널 위에
  따로 뜬 카드라 `panelTopInset`(136 + 머리 높이)만큼 패널을 내려 앉혔다. 도킹하면 패널이 헤더 아래부터 붙으므로, 머리는 패널
  안 첫 블록(검색 위)이 되고 아래 1px 경계로 가른다. `panelTopInset` 은 `lg` 에서 쓸 일이 없어진다.
- 머리 카드는 이 화면의 **유일한 퇴로**(일정으로 돌아가기)다(#556). 패널을 접으면 함께 접히므로 **접힌 동안에도 돌아가기가
  닿아야 한다** — **구현 결정(2026-10-08)**: 버튼 하나가 아니라 **머리 카드 전체**가 접힌 동안 왼쪽 위(`left-4 · top-6`)에 뜬다
  (모바일과 같은 떠 있는 기둥). 열리면 기둥은 `lg:hidden`, 패널 안 머리가 대신 선다 — 한 번에 하나다. 접는 순간 스택이
