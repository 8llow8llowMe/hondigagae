## D0. 왜 다시 하나 — 지난 판의 진단

#1227 · #1230 의 본문은 **설계가 아니라 나열**이었다. 상세 화면의 함수(판정 요약 줄 · 방문 정보 라벨)를 재사용하는 데 맞췄고,
그 결과 라벨-값 표가 세 번 반복됐다. 실화면(`수월봉`)에서 드러난 결함:

| 증상                                                     | 원인                                                               |
| -------------------------------------------------------- | ------------------------------------------------------------------ |
| `몽` 이 라벨 칸에 혼자 선다                              | 반려견 이름을 `dt` 에 넣었다 — 무엇의 라벨인지 말하지 않는다       |
| `적합도 여행 적합`(배지)과 `여행 적합`(줄)이 같은 말     | 등급을 배지와 줄 두 곳에서 말했다                                  |
| `여행 적합` 아래 `붐빌 것으로 예상` — 결론과 근거가 반대 | 영향이 큰 근거 **첫 줄**을 부호와 상관없이 붙였다                  |
| 판정 · 이용 안내가 같은 무게                             | 둘 다 라벨-값 표 — 결론 · 참고 · 행동의 위계가 없다                |
| `064-… · 길찾기` 가 행동으로 안 읽힌다                   | 본문 글줄 속 링크 — 버튼 모양이 아니다                             |
| 사진을 끌어 놓으면 툭 붙고, 조금 끌면 되돌아간다         | 놓을 때 스냅만 다시 켠다 — 방향 · 속도를 안 보고 애니메이션도 없다 |

**원칙(이번 판)**: 한 화면에 **결론 하나 · 행동 하나 줄 · 참고는 접어서**. 같은 사실은 한 번만. 라벨 칸(`dt`)으로 위계를 대신하지 않는다.

### ① 이름 + 분류

- 이름 `text-title-2 font-bold`, 바로 옆(같은 줄 baseline)에 분류 `text-body-2 text-fg-muted` — `contentType.name`(서버 문구).
  원천 분류(`sourceCategory`)가 더 구체적이면(`카페` · `펜션`) 그것을 쓴다.
- **이름 옆 적합도 배지를 걷는다.** 적합도는 ⑤ 카드 하나가 말한다(같은 사실 한 번).

### ② 상태 줄

- `[운영 상태] · [짧은 주소] · [거리]` 한 줄, 넘치면 말줄임.
- 운영 상태: `openNow` 가 참이면 `● 영업 중`(점과 글자 `--metric-high-700`, 굵게), 거짓이면 `영업 시간 아님`(muted),
  판정이 없으면 운영시간 원문 첫 줄(`hoursHeadline`, muted). 원문도 없으면 칸이 빠진다. (규칙은 D5-5 그대로 — 원문 없으면 판정도 없다)
- 거리: 거리순 목록에서 왔을 때만(`distanceMeters`).
- **#1226 의 방문 핵심 줄(`PlaceVisitKeyLine`)은 미리보기에서 쓰지 않는다** — 운영은 이 줄이, 전화 · 길찾기는 ④ 가 맡는다.
  상세 화면의 핵심 줄은 그대로다.

### ③ 속성 칩

- 동반: `petAllowanceType.name` + 허용 크기(`allowedPetSize.name`) — `Badge neutral sm`, 앞에 발 아이콘.
  `UNKNOWN` 이면 점선 `동반 정보 없음`(기존 `MetricBadge unknown` 규칙).
- 실내/야외: `indoor` 낱말 칩. 모르면 점선 `실내 여부 미확인`.
- 칩은 **사실**만 — 판정(적합 · 안전)은 칩으로 만들지 않는다(판정 축은 ⑤).

### ④ 행동 줄

- **아이콘 + 짧은 글자 버튼 4칸, 같은 폭**(`grid-cols-4`), 높이 56(아이콘 20 위 · 글자 `text-caption` 아래), 면 `bg-band`, `rounded-md`.
  - **길찾기**(`DirectionsIcon`) — 카카오맵 외부 링크(`directionsUrl`), 좌표 없으면 버튼이 **비활성**으로 선다(자리 유지 — 칸 수가 바뀌면 손이 헷갈린다).
  - **전화**(`PhoneIcon`) — `tel:` 링크, 번호 없으면 비활성. 번호는 버튼에 쓰지 않는다(이름은 `전화 064-…` 로 sr 에만).
  - **저장**(`BookmarkIcon`) — 즐겨찾기 토글(`aria-pressed`), 미로그인이면 로그인 안내 시트. 저장되면 채운 아이콘 + `저장됨`.
  - **공유**(새 공유 아이콘 — DESIGN.md 아이콘 규칙으로 그린다) — **장소 상세 주소**(`{origin}/places/{placeId}`)를 공유한다.
    지도 주소(`?place=`)가 아니라 상세 주소인 이유: 받는 사람은 지도 맥락이 없고, 상세는 정규 주소 · 공유 카드(OG)가 이미
    있다(#1130 · #1186). `navigator.share({ title, url })` 가 있으면 그것을, 없거나 거절되면(데스크톱 대부분) **링크 복사**
    (`navigator.clipboard.writeText`) 후 토스트 `링크를 복사했어요`. 사용자가 공유 시트를 닫은 것(`AbortError`)은 실패가 아니다
    — 아무것도 띄우지 않는다. 클립보드도 막히면 토스트 `링크를 복사하지 못했어요`.
- 4칸 폭: 패널 400 − 인셋 40 = 360 → 칸당 약 84, 시트 375 − 32 = 343 → 약 80. 글자는 두 글자(`길찾기` 만 세 글자)라 넘치지 않는다.
- 하단 바에서 저장 아이콘을 뺀다 — 하단은 ⑧ 하나.

### ⑤ 오늘 판정 카드 — 이 서비스의 차별점

- 면: `bg-band` 채움 카드(L2 — 아이템 채움, DESIGN.md §0), `rounded-lg`, 안쪽 16. 테두리 없음.
- **머리**: `오늘 {반려견 이름}와/과`(`withCompanionParticle` — `몽` 이면 `오늘 몽과`) — 반려견이 없으면 `오늘 이 장소`.
- **결론 — 서술형 한 문장**(사용자 결정): 서버가 내려 주는 `headline`(BE **#1234** 요청 — `오늘 가기 좋아요` ·
  `가도 괜찮지만 챙길 게 있어요` · `오늘은 다른 곳이 더 나아요` 같은 한 문장)을 `text-title-3 font-bold` 로 크게 쓴다. 그 아래
  작게 등급 배지(`MetricBadge`, 서버 `name`). **FE 가 등급 code 별 한국어를 만들지 않는다**(enum 규칙) — 그래서 서버 문구다.
  - **`headline` 이 `null` 이거나 아직 안 오면(#1234 배포 전)** 등급 `name`(`여행 적합`)을 결론 자리에 크게 쓰고 배지는 생략한다
    — 같은 말 두 번을 피한다. 타입은 `headline?: string | null` 로 두고 계약 스냅샷이 갱신되면 필수로 올린다.
- **근거 사실 2~3줄**(아이콘 + 짧은 사실, `text-body-2`):
  - 날씨: `suitability.weather` — 하늘(`skyState.name`) · 최고 `maxTemperature`° · 비 `maxPrecipitationProbability`%. 아이콘은 하늘 상태별(`SunIcon` · `CloudIcon` · `RainIcon` …).
  - 지금 산책: `walkSafety.walkSafetyLevel.name` · 체감 `feelsLikeCelsius`°. 더 안전한 시간대(`saferWindowStart~End`)가 있으면 `· {시간} 이 더 좋아요` 를 붙인다.
  - 붐빔: `suitability.congestion` — `level.name` · 집중률 `concentrationRate`%.
- **좋은 쪽 / 주의 쪽을 가른다.** 사실마다 톤을 정한다 — 산책은 `walkSafetyLevel` 톤, 붐빔은 `level` 톤, 날씨는 강수확률 · 특보로.
  주의 톤 사실은 **주의 아이콘 + `--metric-mid-700` 글자**로, 좋은 쪽 사실보다 **아래**에 둔다. 결론(적합)과 주의 사실이 함께
  서도 "전체는 좋지만 이것은 조심" 으로 읽힌다 — 지난 판처럼 결론 바로 밑에 반대 문장이 붙지 않는다.
- **근거 문장(`reasons[].description`)은 카드에 싣지 않는다** — 긴 서술이고 부호가 섞여 위 결함을 만든다. 근거 전문은
  `상세 정보 전체 보기` 의 판정 카드 몫이다.
- 반려견이 없으면: 결론 아래 `반려견을 등록하면 크기 · 민감도까지 반영해요 ›`(로그인/등록 링크) 한 줄. 근거 사실은 그대로.
- 로딩: 카드 모양 골격(머리 · 결론 막대 · 사실 3줄 막대) — `bg-band` 카드 위 골격은 `bg-bg` 로 대비(카드 안 골격 전용 갈래를
  `Skeleton` 에 추가 — 컴포넌트 `className` 으로 색을 덮지 않는다, component-guide §3). 판정 하나가 실패하면 그 사실 줄만 빠진다.

### ⑥ 이용 정보 — 아이콘 행

- 라벨 칸(`dt`) 없이 **아이콘 + 값**(네이버 정보 탭). 아이콘 20, 값 `text-body-2`.
  - 🕐 운영: 운영시간 원문(첫 줄) + 휴무(`restDate`) — 한 행. 원문이 여러 줄이면 행을 눌러 펼친다(`aria-expanded`).
  - 🅿 주차: `parking`.
  - 📍 주소: 전체 주소 + `복사` 버튼(클립보드, 토스트 `주소를 복사했어요`).
  - 접힘 `더보기 ⌄`: 유모차 대여 · 신용카드 · 문의처(전화와 다를 때).
- 값이 없는 행은 빠지고, 전부 없으면 절이 없다.
- 필요한 아이콘(주차 · 위치핀)은 기존 `PinIcon` 을 쓰고, 주차는 새로 그린다(DESIGN.md 아이콘 규칙 — 선 굵기 · 24 격자 맞춤).

## D3. 사진 캐러셀 — 부드럽게 넘기기

지금(`useDragScroll`): 끄는 동안 스냅을 끄고 `scrollLeft` 를 직접 쓰다가, 놓으면 스냅을 다시 켠다 → 브라우저가 **애니메이션 없이**
가장 가까운 칸으로 붙는다. 방향 · 속도를 안 봐서 30% 끌어도 되돌아간다.

- **놓을 때 목표 칸을 직접 고른다**: 끈 거리 ≥ 칸 폭의 **15%** 이거나 속도 ≥ **0.3 px/ms**(마지막 80ms 기준)면 끈 방향의 다음
  칸, 아니면 제자리. 그 칸으로 `scrollTo({ left, behavior: 'smooth' })`, **스크롤이 끝난 뒤**(`scrollend`, 미지원이면 시간 폴백)
  스냅을 다시 켠다.
- **터치는 그대로 네이티브**(관성 · 스냅) — 지금 규칙(#247 `useDragScroll` 머리주석) 유지.
- **데스크톱 이전/다음 버튼**: 사진 위 좌우 세로 중앙, 원형 44(`bg-bg/90` · 그림자), **마우스를 올렸을 때 · 포커스가 있을 때만**
  보인다. 첫 칸에서 이전, 끝 칸에서 다음은 숨긴다. 한 칸씩 부드럽게(`scrollBy` smooth).
- **키보드**: 캐러셀에 포커스가 있으면 ← → 로 한 칸.
- `prefers-reduced-motion` 이면 smooth 대신 즉시.
- **같은 캐러셀을 상세 모바일도 쓴다** — 상세도 함께 좋아진다(회귀 확인 대상).
- 사진 출처(`한국관광공사`, D5-2 필수 표기)는 갤러리 아래 줄에서 **사진 위 좌하단 작은 글자**(반투명 바탕)로 옮긴다 — 미리보기 한정.
  상세 화면 출처 줄은 그대로.

## D4. 크기 · 간격
