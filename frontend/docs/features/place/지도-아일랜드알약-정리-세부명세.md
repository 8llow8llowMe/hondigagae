## D6. 접근성

- **랜드마크**: ≥768 은 지금과 같다 — `banner` 1(알약 헤더) · `nav "주요"`(펼침 · `≡` 모두 이 안). **<768 은 `banner` 0** — 남는 것은 `main` · `nav "하단"` · `h1`(sr-only). D1-2 권고대로 받아들인다.
- **건너뛰기 링크**: 무변화. <768 지도에서는 첫 탭 정류장이고 목적지(`#main`)가 바로 검색 앞이다.
- **포커스 순서**: 스킵 링크 → (≥768) 로고 → 메뉴 셋 또는 `≡` → 계정 → 본문(검색 → 목록 아이콘/`목록 보기` → 병원·약국 칸 → 내 위치 칸 → 안내 카드 → 재검색 → 스택 → 시트). 데스크톱 스택 안: 검색 → 필터 → **`크게 보기`** → 목록 행 → 미리보기(`‹ 목록` → ✕ → 본문).
- **이름**: 아이콘만 남는 조작은 전부 이름이 있다 — 계정 `내 정보 메뉴 열기` · `≡` `메뉴 열기` · 병원·약국 칸 = 보이는 캡션 `병원·약국` · 내 위치 `내 위치로 이동`. 켬/끔으로 이름을 바꾸지 않는다(#1286).
- **터치 · 클릭 크기**: 알약 안 40 은 44 하한 아래다 — **데스크톱 · 태블릿(포인터)에만 선다**(<768 은 알약이 없다). 768–1023 터치 태블릿은 WCAG 2.5.8(24) 를 넉넉히 넘는다. 카드 칸 48 · 목록 아이콘 44 · `크게 보기` 44 · 요약 링크 `min-h-11`.
- **대비**: 캡션 10px 은 `text-fg-muted`(끔) / `text-fg-inverse` on `bg-fg`(켬) — 둘 다 기존 토큰 쌍(4.5:1 이상). 작은 글자라 굵기 600.
- **움직임**: 새 전환 없음. `≡` ↔ 펼침은 즉시.

## D10. 구현 중 바뀐 것 (2026-10-09)

### D10-1. `≡` 기준값 — px 하나가 아니라 `calc(221px + 8.625rem)`

D1-2 는 "실측 비로그인 폭(px)" 하나를 기준으로 적었다. 실측해 보니 **글자 크기 토큰은 px 이고 여백(`px-3` · `p-1` · `h-10`)만
rem** 이라, 뿌리 글자 크기를 키우면 알약이 rem 몫만큼만 자란다 — 100 % 358.5 · 112.5 % 375.7 · 125 % 393 · 150 % 427.5.
px 하나(359)면 150 % 에서 상자 424 보다 큰 알약이 접히지 않고 3px 넘친다. 고정 몫 221px + rem 몫 8.625rem 으로 적어 두 경우를
다 맞춘다(16px 에서 359, 24px 에서 428). 컨테이너 쿼리 안 `calc()` · `rem` 은 Chromium 에서 실측으로 동작을 확인했다.

브라우저 확대(Ctrl +)는 CSS 폭이 줄어 더 좁은 배치(1024 · 태블릿)로 내려가므로 이 기준에 닿지 않는다 — D7-6 의 "브라우저 확대
에서 `≡` 가 선다" 는 기대는 글자 크기 확대에서만 맞는다.

### D10-2. `≡` 메뉴 자리 — 트리거가 아니라 알약 오른쪽 끝 아래

트리거(`≡`)는 접힌 알약 맨 왼쪽이다. 트리거 기준 `end-0` 이면 패널(176)이 왼쪽으로 나가 허용 상자 밖 미리보기 위로, `start-0` 이면
1280 에서 오른쪽 뷰포트 밖(1295)으로 나갔다. 알약에 `relative` 를 주고 메뉴를 `end-0 top-full` 로 세워 **알약 오른쪽 끝 = 허용 상자
오른쪽 끝**에 맞췄다. 접힌 갈래는 `MenuAnchor` 로 감싸지 않는다.

### D10-3. `‹ 목록` 비킴 — 패딩이 아니라 빈 자리 폭

`lg:max-xl:ps-34`(136)는 §4 간격 스케일 밖이라 `token-usage.test.ts` 가 막는다. 패딩 대신 `‹ 목록` 앞에 1024–1279 에서만 서는
빈 자리 `w-31`(124, 크기라 스케일 대상 아님)을 둔다 — 안쪽 8 + 124 + 간격 4 = **136** 에서 `‹ 목록` 이 시작한다(실측 x 136).

### D10-4. 간격 2 → 4

병원·약국 칸의 아이콘–캡션 간격(D1-2 "간격 2") · `크게 보기` 글자–화살표 간격을 4(`gap-1`)로 둔다 — 2(`gap-0.5`)는 §4 스케일
밖이다. 칸 안 세로 합은 20 + 4 + 12 = 36 으로 48 안이다.
