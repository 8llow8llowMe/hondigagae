# 장소 탐색 공통 명세

> 작성일: 2026-08-26
> 관련 백엔드 서비스: `tour-service` (place 컨텍스트)
> **계약 확인 근거**: 백엔드 소스 실측 — `PlaceWebController`, `PlaceItem`, `PlaceDetailResponse`,
> `ContentType`, `PetAllowanceType`. **로컬 Swagger 미기동 상태라 실호출 확인은 하지 못했다.**
> 백엔드 기동 후 `/fe-api-check` 로 재검증한다.

## S0. 개요

- **한 줄 정의**: 반려견과 갈 수 있는 제주 장소를 조건으로 찾아본다.
- **사용자가 달성하려는 것**: 반려견 동반 가능 여부와 장소 종류로 후보를 좁혀 상세로 진입한다.
- **범위에 포함**: 목록 조회, 필터, 무한 스크롤, 카드 표시, 상세 진입
- **범위에서 제외**:
  - 지도 뷰 — 별도 작업 (`external-api-guide.md`)
  - 상세 화면 — 별도 명세
  - 정렬 — **백엔드에 정렬 파라미터가 없다**
  - 즐겨찾기 / 여행 적합도 — 백엔드 미착수 (`screen-inventory.md` §6)

## S2. 사용 API

| #   | METHOD 경로          | 용도      | 인증   | 비고                      |
| --- | -------------------- | --------- | ------ | ------------------------- |
| 1   | `GET /api/v1/places` | 목록 조회 | 불필요 | 커서 기반 `SliceResponse` |

### 쿼리 파라미터 (백엔드 `PlaceWebController` 실측)

| 이름               | 타입   | 필수 | 기본값 | 비고                                    |
| ------------------ | ------ | ---- | ------ | --------------------------------------- |
| `areaCode`         | String | 선택 | —      | 제주 = `39`                             |
| `sigunguCode`      | String | 선택 | —      |                                         |
| `contentType`      | enum   | 선택 | —      | **단일값**. name() 기준 바인딩 전제     |
| `petAllowanceType` | enum   | 선택 | —      | **단일값**                              |
| `lastPlaceId`      | Long   | 선택 | —      | **커서 — 직전 응답의 마지막 `placeId`** |
| `size`             | int    | 선택 | `20`   | 허용 `1~50`. 벗어나면 400               |

**모두 단일값이다. 배열 파라미터가 없다.**

### enum 값

- `contentType`: `TOURIST_SPOT`(12) `CULTURE`(14) `FESTIVAL`(15) `COURSE`(25) `LEPORTS`(28) `LODGING`(32) `SHOPPING`(38) `RESTAURANT`(39)
- `petAllowanceType`: `ALLOWED` `PARTIALLY_ALLOWED` `NOT_ALLOWED` `UNKNOWN`

> **미결(BE 확인 필요)**: Spring 기본 바인딩은 `name()` 기준이므로 `?contentType=TOURIST_SPOT` 을 전제했다.
> 코드값(`"12"`) 바인딩용 컨버터가 있는지 Swagger 로 확인한다.

## S3. 데이터 모델

`dataBody` 기준. 공통 래퍼는 `docs/api-integration-guide.md` §2 참조.

```ts
type SliceResponse<PlaceItem> = { contents: PlaceItem[]; hasNext: boolean }

type PlaceItem = {
  placeId: string // 문자열이다. 백엔드 내부는 long(Snowflake 크기)
  contentType: { code: string; name: string; description?: string | null }
  title: string
  addr1: string | null
  sigunguCode: string | null
  lat: number | null // 위도. 백엔드가 Double 로 정규화
  lng: number | null // 경도
  firstImage: string | null // TourAPI 외부 원본 URL
  firstImage2: string | null
  petAllowanceType: { code: string; name: string; description?: string | null }
  tel: string | null
}
```

| 항목          | 내용                                                                        |
| ------------- | --------------------------------------------------------------------------- |
| nullable 필드 | `addr1` `sigunguCode` `lat` `lng` `firstImage` `firstImage2` `tel`          |
| 문자열 ID     | `placeId` — **`number` 로 타이핑 금지**                                     |
| enum metadata | `contentType` `petAllowanceType` — **서버 `name` 을 그대로 렌더한다**       |
| 단위          | 좌표는 도(degree). 거리 계산은 이 화면 범위 밖                              |
| 외부 이미지   | `firstImage` 는 TourAPI 원본 URL → `next.config` `remotePatterns` 등록 필요 |

## S4. 상태 / 에러

| 상태        | 조건                   | 화면                           | 문구 (확정)                                                                   |
| ----------- | ---------------------- | ------------------------------ | ----------------------------------------------------------------------------- |
| loading     | 최초 진입 / 필터 변경  | `Skeleton` 카드 6개            | —                                                                             |
| success     | `contents.length > 0`  | 카드 목록                      | —                                                                             |
| empty       | `200` + `contents` 0건 | `EmptyState` (**재시도 없음**) | "조건에 맞는 장소가 없습니다." / "필터를 바꿔 다시 찾아보세요."               |
| 데이터 부재 | `404`                  | `EmptyState` (**재시도 없음**) | 서버 `resultMessage` 그대로 + 위 안내                                         |
| 일시 장애   | `5xx` · 무응답         | `ErrorState` (**재시도 있음**) | "장소를 불러오지 못했습니다." / "잠시 후 다시 시도해 주세요." / `[다시 시도]` |
| 입력 오류   | `400` (`size` 범위 등) | `ErrorState`                   | "요청 조건이 올바르지 않습니다." / `[필터 초기화]`                            |

**nullable 처리 (에러가 아니라 숨김)**

| 필드 없음    | 처리                                             |
| ------------ | ------------------------------------------------ |
| `firstImage` | 이미지 자리에 플레이스홀더. 카드 레이아웃은 유지 |
| `addr1`      | 주소 줄 숨김                                     |
| `tel`        | 전화 줄 숨김                                     |
| `lat`/`lng`  | 목록에는 영향 없음 (지도 뷰에서 마커 제외)       |
