## D0. 화면 정의

- 경로 `/about`. **보호 경로가 아니다.** 미로그인 모바일 방문자(심사자 포함)가 대상이다.
- 역할: 서비스가 무엇을 판단하고 왜 믿을 수 있는지 한 화면에서 답하고 홈으로 보낸다. 홈과 경쟁하지 않는다 — 예시는 전부 고정값.
- 청중 우선순위: 첫 동반여행 보호자 → 여행 중 보호자 → 심사자(마지막 절).

## D1. 레이아웃

- 8절: 히어로(그린) · 데려가도 돼요?(바닥) · 지금 나가도 돼요?(연녹) · 오늘 어디 가요?(바닥) · 위급하면?(연녹) · 무엇을 보고 판단하나요 + 알아두실 점(바닥) · CTA(그린).
- 밴드는 `Canvas` 안 전폭, 안쪽 1152(`max-w-6xl`). `SurfaceStack` 없음.
- 375: 1단, 카드 전폭(`-mx-4`). 1024: 히어로 2열(카피 7 : 예시 5, 12열 그리드), 질문 절 5:7. 질문 3 은 1024 미만 가로 칩 + 예시 카드 하나, 1024 이상 목록 5 : 예시 7 이고 절이 헤더 아래 한 화면을 채운다 (#940).
- 히어로 예시 열이 12 중 5 인 이유는 폭이다. 3열 배치(`lg:grid-cols-3`)면 1024 에서 판정 카드가 272px 로 모바일보다 좁아져 카드 안 수치 세 개가 한 줄에 서지 못한다. 12열 5칸은 `gap-16` 기준 1024 에서 356px, 1280 에서 409px 로 모바일(358px)보다 좁아지지 않는다.

## D4. 상호작용

- 스크롤 등장: 뷰포트 하단 10% 진입 시 200ms, 형제 60ms. 로드 시 보이는 요소는 등장하지 않는다.
- 예시 재생: 진입 시 1회. 무한 반복 없음. `prefers-reduced-motion` 이면 즉시 끝 상태.
- **만져 보는 예시** (#916, 설계 명세 2026-09-25 §5): 질문 1 필터 칩 둘이 눌려 조건에 안 맞는 행이 흐려진다(행을 지우지 않음) · 질문 2 곡선 시각 핸들(0–23시 range, 24점 예시 표, 만지기 전에는 읽기 줄 없음) · 질문 3 혼잡도 막대 툴팁(버튼, 날짜 · 서버 어휘 수준) · `하루만 다시 짜기` 시연(진행 단계 셋 500ms 씩 → 고른 일자 대체 세트, 다시 누르면 원래대로).
- **스크롤 무대** (#914 · #940): 항목의 **중심**이 기준선(헤더 아래 화면의 가운데 = 고정 카드 중심, 질문 2 는 개 + 카드 덩어리 중심)을 지나면 그 항목이 켜지고 예시가 그 단계 모양이 된다. 단계표는 설계 명세 2026-09-25 §3-2, 개정은 §3-5. 1024 이상에서 항목 하나가 뷰포트 58% 높이이고, 예시 열은 헤더 아래 화면 높이의 sticky 틀이며 예시는 그 안 세로 가운데(최대 560)다. 번호 칸 기본 모양은 채움(끝 상태)이고, 재기가 걸리면 지금 항목은 채움 · 지나온 항목은 브랜드 테두리 · 아직 안 온 항목은 회색 테두리이며 문장이 `--fg-muted` 로 낮아진다(1024 이상). 번호 잇는 선은 지나온 구간만 브랜드색이다. 카피 열 끝 꼬리 여백이 마지막 항목이 켜지는 순간 무대 끝을 화면 바닥에 닿게 해, 그다음 스크롤부터 문장과 예시가 함께 올라간다. 고정 카드 위 맥락 줄은 `표지어 · 제목`(절 제목이 헤더 밑으로 사라진 뒤 드러남) + 바로가기다. 1024 미만은 쌓기 흐름 그대로이고 문장을 흐리지 않는다 — 번호 칸만 갈린다. 본문 크기가 바뀌어도 다시 잰다(`ResizeObserver` — 1024 미만 질문 3 탭 전환이 문서 높이를 바꾼다). **되돌리면 되돌아간다** — 1회 재생이 아니다. 스크롤마다 한 프레임에 한 번 잰다(passive `scroll` + rAF). 감속 모션이면 재지 않고 마지막 단계에 고정한다.
- 무대 안 예시는 `Reveal` 로 감싸지 않는다 — 무대가 등장을 대신한다.
- **첫 화면 리듬** (#915): 히어로 제목이 어절마다 60ms 씩 200ms 로 올라온다(CSS). 1024 이상에서 히어로가 첫 화면(헤더 아래)을 채우고, 판정 카드가 스크롤의 0.12배로 거슬러 오르며(최대 108px), 카피 아래 스크롤 힌트가 질문 1 절로 가는 앵커로 선다(40px 내려가면 사라짐). 1280 이상 왼쪽에 절 내비(1536 이상에서 라벨까지), 1024 미만 헤더 아래 진행선. 규모 숫자는 화면에 들어올 때 한 번 센다. 스크롤 연동은 전부 `useScrollFrame`(passive scroll + rAF) 하나로 잰다.
- **캐릭터** (#917): 히어로 개는 제목 어절 뒤 500ms 에 한 번 올라온다(`about-word-in` 200). 1024 이상은 판정 카드 왼쪽 바깥(카드 패럴랙스를 같이 탄다), 그 미만은 카드 **아래** 왼쪽에서 절 끝선에 발을 댄다. 질문 2 는 단계 0 · 1 · 3 목줄 산책, 2 · 4 앞발 + 열기 선이고, 시각 핸들을 만지면 판정(안전 산책 · 주의 서기 · 위험 앞발)이 고른다 — **마지막 사건이 이긴다**(핸들 뒤 단계가 바뀌면 단계가 고른다). 전환은 투명도 150, 열기 선 200. 곡선 카드와 함께 가운데 서는 예시 덩어리(`.about-stage-frame`)에 자세 높이만큼 위 여백(`about-pose-room`)이 붙고, 1024 이상에서 맥락 줄은 그 여백 안 왼쪽에 두 줄로 선다(#940 — 예전 카피 열 아래 여백 `about-pose-tail` 은 틀이 화면 높이가 되며 걷었다). 창 높이 720 미만은 개를 모바일 크기로 줄여 덩어리가 헤더 아래 화면에 들어오게 한다. 마무리는 1024 이상 7:5 의 오른쪽 열, 그 미만은 버튼 아래 오른쪽이고 둘 다 절 끝선에 발을 댄다(`Reveal` 1회).
- 절 앵커: `about-hero` · `about-q1` · `about-q2` · `about-q3` · `about-q4` · `about-data`. 제목 id 와 따로 둔다 — 앵커로 가면 절 맨 위가 와야 해서. 헤더 높이만큼 스크롤 여백(`.about-anchor`)이 있어 `처음` 은 맨 위(`scrollY = 0`)로 간다.
- 절 내비는 1280 이상에서 본문(`main`)이 끝나면 숨는다 — 1280×800 등에서 푸터 문구를 가리지 않게. 규모 숫자는 셀 준비 중에 0 을 보인다.
- **질문 3 목록** (#940): 네 항목(여행 적합도 · 한산한 날 · AI 일정 · 비가 오면 실내로)을 눌러 예시 하나를 고른다. 자동 순환 없음 · URL 에 두지 않는다(고정값 예시 시연). 고른 패널만 서고 200 동안 떠오른다 — 카드 높이는 패널마다 다르지만 1024 이상에서 왼쪽 열과 세로 가운데라 절 높이는 그대로다. 탭은 roving tabindex(고른 탭만 `0`) + 화살표 네 방향 · `Home` · `End`.
- 바로가기(`MoreLink`)는 `text-body-1` 이다 — 항목 문장보다 작지 않게. 무대 절은 1024 이상에서 맥락 줄의 것 하나만 서고 항목 아래 것은 `lg:hidden` 이다.
- AI 일정 탭: 눌러서 3세트 전환. 자동 순환 없음. 탭 버튼은 `min-h-11`(44px 터치 영역) + roving tabindex — 활성 탭만 `tabIndex={0}`, 나머지는 `-1`. `ArrowRight`/`ArrowLeft`(암시)/`Home`/`End` 로 포커스를 이동한다.
- 링크 5개: `/` `/places` `/ai-plans/new` `/emergency` `/pets/new`. 보호 경로는 proxy 가 `returnTo` 를 붙인다. 그 밖의 링크는 전부 같은 화면의 절 앵커(`#about-*`)다 (#915).

## D6. 접근성

- `h1` 보임. `h2` 는 `lg:` 상향(DESIGN.md §3-1 #358). 절은 `section` + `aria-labelledby`.
- 그래프는 `role="img"` + 한 문장. 카운트업 중간값은 `aria-hidden`, 최종값은 `sr-only`.
- 등급·상태는 글자가 먼저(`위험` · `적합도 여행 적합` · `진료중`). 적합도·혼잡도 배지는
  축 라벨을 앞에 세운다 — 등급어는 서버 `name` 그대로다 (#652).
- 그린 면 위 글자 `--fg-inverse` on `--brand-700` 6.91:1. 버튼 최소 44.
- **히어로 제목은 한 문장으로 읽힌다** (#915) — `h1` 안에 원문 `sr-only` 텍스트, 어절 조각은 `aria-hidden`. 감속 모션이면 어절이 한꺼번에 끝 상태로 선다(전역 규칙이 `animation-delay` 도 끈다).
- **절 내비는 랜드마크가 아니다** (#915) — `nav` 없이 이름 있는 목록(`ul aria-label`)이고, 현재 절은 `aria-current="true"`, 링크 44. 링크 이름은 각 절의 제목(h2)이다. 본문이 끝나면 `inert` 로 숨는다. 스크롤 힌트는 사라진 동안 `tabIndex=-1` · `aria-hidden`. 진행선은 `aria-hidden` 장식.
- **만져 보는 예시의 접근성** (#916) — 칩은 `button` + `aria-pressed`, 누르는 자리 46(`before:`). 시각 핸들은 `<label>` 이 붙은 `input type="range"` 이고, 읽기는 `aria-valuetext` 하나다(화면 읽기 줄은 `aria-hidden` — `aria-live` 를 더하면 두 번 읽힌다). 혼잡도 막대는 `role="group"` 안의 버튼(이름 = 툴팁 문장, 툴팁은 `aria-hidden`, 탭은 열기만). 다시 짜기는 `button`, 진행 · 끝 문장은 `aria-live`, 진행 중 `aria-disabled`(포커스를 잃지 않게). 무대 단계 0 의 칩은 `visibility: hidden` 이라 탭 순서에서도 빠진다.
- **스크롤 무대의 단계는 시각 강조다** (#914). 항목 문장과 예시의 끝 상태 내용은 처음부터 DOM 에 있고, 읽는 순서도 끝 상태 그대로다(긴급 예시의 거리순 정렬은 `transform` 뿐). 단계가 바뀌어도 알리지 않는다(`aria-live` 없음) — 스크롤할 때마다 읽으면 소음이다. 위치 점은 `aria-hidden` 장식이다.
- **맥락 줄 제목은 `aria-hidden` 이다** (#940) — 같은 절 `h2` 의 되풀이다. 바로가기는 1024 이상에서 맥락 줄 것 하나만 트리에 있다(항목 아래 것 `lg:hidden` · 1024 미만은 맥락 줄이 `display: none`). 단계 번호 칸은 `aria-hidden` 이고 항목 목록은 `ol` 이다.
- **질문 3 은 WAI-ARIA Tabs 다** (#940) — `tablist`(이름 `기능 예시 네 가지`, `aria-orientation` 은 보이는 방향 — 1024 이상 세로) · `tab` · `tabpanel` 이 서로를 가리킨다. 탭 이름은 제목만이고, 1024 이상에서 고른 탭 아래 펼치는 설명은 `aria-hidden` — 같은 설명을 패널 머리(`lg:sr-only`)가 읽는다. 숨은 패널은 `display: none` 이라 안의 버튼이 탭 순서에 없다. AI 일정 예시의 일자 탭 목록이 패널 안에 따로 있다.
- **캐릭터는 스크린리더에 없다** (#917) — `alt=""` + 감싸는 `span` 의 `aria-hidden`. 자세가 바뀌어도 알리지 않는다. 포인터 이벤트도 받지 않는다(`pointer-events: none`) — 카드 가장자리에 겹친 개가 클릭을 가로채지 않는다.
- 골든타임 곡선(`GoldenCurveSpecimen`)은 `max-w-md` 로 렌더 폭을 묶고, y축 눈금 라벨을 두지 않는다 — 정확한 수치를 읽는 그래프가 아니라 "낮에 걷기 좋은 시간대가 있다"는 인상만 주는 일러스트라서다. 수치는 `role="img"` 의 한 문장으로 전달한다.
