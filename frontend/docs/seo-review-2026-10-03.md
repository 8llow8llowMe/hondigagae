# 혼디가개 검색 노출(SEO) · 성능 검토 (2026-10-03)

> 목표: 구글(과 네이버)에서 **"반려견 · 강아지호텔 · 제주 강아지"** 류 검색에 상단 노출.
> 방법: ① 코드 정독(`app/**` 메타데이터·라우트·`proxy.ts`·`next.config.ts`) ② 배포 사이트
> 실측(`curl` 로 상태 코드·헤더·SSR HTML 파싱) ③ **Lighthouse 12 모바일**(Moto G Power ·
> 느린 4G 시뮬레이션)로 dev 5개 화면 측정 ④ 공개 API 로 장소 데이터 전수 집계(2,323곳).
> 운영(`www`)이 502 라 **측정은 전부 `dev.hondigagae.com` 기준**이다. dev 는 nginx 가
> `X-Robots-Tag: noindex` 를 붙이므로 Lighthouse SEO 점수(0.60~0.63)는 그 감점이 대부분이다.

## 0. 총평

**지금 상태로는 어떤 키워드로도 노출되지 않는다.** 콘텐츠 이전에 "구글이 사이트를 읽을 수
있는가" 단계에서 막혀 있다.

1. **운영 도메인이 죽어 있다.** `https://www.hondigagae.com/` 이 **502**, `http://www…` 는
   **`https://ai.8llow8llowme.com/` 으로 301** 된다(다른 서비스로 영구 이전 신호). `dev` 도 같다.
2. **크롤러용 기본 파일이 없다.** `robots.txt` · `sitemap.xml` 둘 다 없다. 장소 목록은 무한
   스크롤이라 크롤러가 볼 수 있는 장소는 **첫 20곳뿐**이고 나머지 2,303곳은 링크로 닿지 않는다.
3. **모든 페이지의 공유 카드가 홈을 가리킨다.** `og:title`=`혼디가개`, `og:url`=홈 이 전
   페이지 공통이다. 카카오톡·페이스북은 `og:url` 을 정규 주소로 취급해 공유를 홈으로 뭉갠다.
4. **키워드가 제목·본문에 없다.** 홈 `<title>` 이 `혼디가개` 한 단어, 장소 상세는
   `성판악 · 혼디가개`. "반려견 동반", "애견동반 숙소", "강아지" 가 title·h1·description
   어디에도 없다.
5. **성능의 병목은 거의 전부 이미지다.** TourAPI 원본(940×627, 장당 **500~780KB**)을 80px
   썸네일에도 그대로 쓴다. `/places` 한 화면 **7.1MB**(이미지 6.5MB), 장소 상세 LCP **20.8s**.
   썸네일용 `firstImage2`(150×100, **20KB**)가 응답에 이미 있는데 쓰지 않는다.

좋은 점도 분명하다 — 공개 화면이 **서버 렌더(SSR)** 라 본문이 HTML 에 들어 있고, 잘못된 id 는
400·없는 리소스는 진짜 404 로 답하며(soft 404 없음), `lang="ko"`·`metadataBase`·OG 이미지·
접근성(0.96~1.0)이 갖춰져 있다. **기반 공사(P0)만 끝나면 콘텐츠 경쟁에 바로 들어갈 수 있다.**

## 1. 키워드 현실 점검

**"반려견" 단독 1페이지는 목표로 두지 않는다.** 백과사전·포털·정부 사이트가 점유하는 정보형
헤드 키워드라 신규 도메인이 이길 수 없다. 대신 **"제주 + 반려견 + 행동"** 롱테일을 노린다.
이 서비스의 데이터(2,323곳 중 동반 확인 579곳)가 정확히 그 질문에 답한다.

잡으려 하면 이탈률이 높아 오히려 순위가 떨어진다. 꼭 노린다면 "**제주 강아지 호텔**(동반

> 실제 월간 검색량은 확인하지 못했다. 랜딩 문구를 정하기 전에 **네이버 검색광고 키워드 도구**와
> **Google Search Console 실적 보고서**로 검색량·노출 쿼리를 확인하고 표의 순위를 조정한다.

**네이버를 같이 본다.** 한국 검색 점유율은 네이버가 높고, "제주 애견동반" 류는 네이버
블로그·플레이스가 강하다. 구글 작업(사이트맵·구조화 데이터)은 네이버에도 그대로 통하므로
**Search Console 과 네이버 서치어드바이저를 같이 등록**한다(§2-P0-4).

## 2. 해야 할 일 — 우선순위별

표기: **영역** `FE`(이 저장소 `frontend/`) · `BE`(백엔드 이슈로 요청) · `OPS`(nginx·도메인 등
저장소 밖). **공수** S(반나절 이하) · M(1~2일) · L(3일 이상).

### P2 — 오프사이트 · 운영

- **백링크**: 공모전 출품 페이지, 제주 관광 커뮤니티, 반려견 카페에 서비스 링크를 남긴다.
  신규 도메인은 외부 링크가 순위의 큰 축이다.
- **네이버 채널**: 네이버 블로그에 "제주 애견동반 숙소 N곳" 류 글을 랜딩 페이지 링크와 함께
  발행한다. 네이버 검색은 자사 블로그를 우대한다.
- **Search Console 주간 확인**: 색인 생성 범위(제외 사유), Core Web Vitals(실사용자 지표),
  실적(노출되는 쿼리) — 랜딩 문구를 실제 쿼리에 맞춰 고친다.
- **기대 시간**: 새 도메인이 롱테일(장소명 + 강아지)에서 노출되기까지 보통 수 주, "제주
  애견동반 숙소" 같은 중간 경쟁 키워드는 수 개월이다. 순위를 약속할 수 있는 작업은 없다.

### 3-3. 구조적 메모 — 지금은 손대지 않아도 된다

- `(main)` 레이아웃이 `readSession()` 으로 쿠키를 읽어 **모든 페이지가 동적 렌더 +
  `Cache-Control: no-store`** 다. 그래서 CDN 캐시도, 뒤로가기 캐시(bfcache)도 안 된다.
  TTFB 가 100ms 안팎이라 당장은 문제가 아니지만, 크롤러가 사이트맵 2천여 URL 을 훑을 때
  **라즈베리파이가 매 요청을 렌더**한다. 트래픽이 늘면 공개 상세를 ISR(로그인 여부는
  클라이언트에서 판정)로 바꾸는 것을 검토한다.
