# 혼디가개 — 아이덴티티 에셋 v1

`DESIGN GUIDE v1`의 하위 문서입니다. 충돌하면 디자인 가이드가 이깁니다.

## 원칙

**인터페이스 안은 무채색, 인터페이스 밖은 브랜드 컬러.**

가이드 0절에 "인터페이스는 무채색 · 장식 목적의 색은 없다"가 있습니다. 이 규칙은
헤더 로고까지 적용됩니다. 그래서 헤더는 워드마크만 씁니다.

반대로 파비콘·앱 아이콘이 사는 곳(브라우저 탭, iOS 홈 화면, 공유 카드)은 우리 UI가
아니라 남의 UI이고, 네이버·유튜브 아이콘과 나란히 놓입니다. 여기서 무채색은 사라집니다.
**따라서 파비콘에 한해 브랜드 컬러를 씁니다. 이건 예외가 아니라 규칙입니다.**

## 심볼 — 발바닥, 발가락 3개

발바닥은 반려동물 서비스의 클리셰지만 이 제품에서는 아닙니다. 핵심 판정이
"노면 52.4℃ — 발바닥 화상 위험"이고, 발바닥은 이 서비스가 실제로 지키는 대상입니다.

**발가락은 3개입니다. 4개로 늘리지 마세요.** 32px 그리드에서 발가락 반지름 3.24,
발가락 사이 최소 간격 2.39 — 16px로 축소하면 1.2px입니다. 4개로 늘리면 이 간격이
0.5px 아래로 떨어져 하나의 덩어리로 뭉갭니다.

메인 패드는 정원이 아니라 위가 좁고 아래가 넓습니다. 정원이면 "점 4개"로 읽힙니다.

## 넣는 법

```html
<link rel="icon" href="/favicon.ico" sizes="32x32" />
<link rel="icon" href="/favicon.svg" type="image/svg+xml" />
<link rel="apple-touch-icon" href="/apple-touch-icon.png" />
<link rel="mask-icon" href="/safari-pinned-tab.svg" color="#2E9B6B" />
<link rel="manifest" href="/site.webmanifest" />
<meta name="theme-color" content="#FFFFFF" />
<meta property="og:image" content="https://.../og-image.png" />
```

`.ico`와 `.svg`를 둘 다 거는 순서가 중요합니다. `.ico`를 먼저 선언해야 구형 브라우저가
`.svg`를 만나 깨지지 않습니다.

`theme-color`는 `#2E9B6B`가 아니라 `#FFFFFF`입니다. PWA 상태바가 헤더와 이어져야
하는데 헤더 배경이 흰색이기 때문입니다. 초록을 넣으면 상태바만 색 띠로 떠 보입니다.

## 하지 말 것

- **헤더에 심볼 붙이기** — 가이드의 무채색 원칙 위반. 락업은 스플래시·공유 카드 전용
- **파비콘을 원형으로 만들기** — 가이드상 원형은 사진·아바타 전용. 정사각 + 라운드 4
- **워드마크를 라이브 텍스트로 두기** — 폰트 로딩 실패 시 헤더가 시스템 폰트로 튐
- **심볼을 판정 등급 색(danger/high/mid)으로 칠하기** — 브랜드가 등급을 말하게 됨
- **발가락 4개** — 위 참조
