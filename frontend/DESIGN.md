# 혼디가개 Design System

> **이 문서가 디자인 토큰의 단일 정본이다.** 색상·타이포·spacing·radius·shadow는 여기에만 정의한다.
> 상태: **1차 토큰 세트**. 디자이너 확정 시 이 문서를 갱신하고, 코드는 `src/styles/` 의 CSS 변수만 따라간다.
> 적용 규칙과 공통 컴포넌트 목록은 `docs/styling-guide.md`.

## 1. 제품 톤

반려견과 함께하는 제주 여행. **따뜻하되 과장하지 않는다.**

- 사용자는 **여행 중 이동하면서** 본다 → 모바일 1순위, 큰 터치 영역, 짧은 문장.
- 정보 서비스가 아니라 **의사결정 지원** 서비스다 → 추천에는 항상 근거(XAI `reasons`)를 함께 보여준다.
- 마케팅 톤 금지. "최고의", "완벽한" 같은 표현을 쓰지 않는다.

### 용어 (고정)

| 사용             | 금지                 |
| ---------------- | -------------------- |
| 반려견           | 강아지, 애견, 멍멍이 |
| 여행 일정        | 여행 계획, 플랜      |
| 장소             | 스팟, 포인트         |
| 여행 적합도      | 여행 점수, 궁합      |
| 반려견 동반 가능 | 펫 프렌들리          |

## 2. 색상

제주의 자연(초록·바다)을 기본으로 하고, 반려견의 따뜻함을 accent로 둔다.

### 브랜드

| 토큰          | 값        | 용도                                  |
| ------------- | --------- | ------------------------------------- |
| `--brand-50`  | `#EFF8F3` | 배경 강조                             |
| `--brand-100` | `#D6ECE0` | 태그·칩 배경                          |
| `--brand-300` | `#7FC4A2` | 보조                                  |
| `--brand-500` | `#2E9B6B` | **주 브랜드** (버튼, 링크, 활성 상태) |
| `--brand-600` | `#237A54` | hover / 강조 텍스트                   |
| `--brand-700` | `#1A5C3F` | pressed                               |

### Accent (반려견·강조)

| 토큰           | 값        | 용도                    |
| -------------- | --------- | ----------------------- |
| `--accent-100` | `#FDEEE0` | 배경                    |
| `--accent-500` | `#E8843C` | 강조 배지, AI 생성 표시 |
| `--accent-600` | `#C86A28` | hover                   |

### 중립

| 토큰              | 값        | 용도                |
| ----------------- | --------- | ------------------- |
| `--bg`            | `#FFFFFF` | 페이지 배경         |
| `--bg-subtle`     | `#F7F8F7` | 섹션 배경           |
| `--bg-elevated`   | `#FFFFFF` | 카드·모달           |
| `--border`        | `#E3E6E4` | 구분선·테두리       |
| `--border-strong` | `#C8CDC9` | 입력 필드           |
| `--fg`            | `#1A1D1B` | 본문                |
| `--fg-muted`      | `#5F6762` | 보조 텍스트         |
| `--fg-subtle`     | `#8A928C` | 캡션·placeholder    |
| `--fg-inverse`    | `#FFFFFF` | 진한 배경 위 텍스트 |

### 상태

| 토큰            | 값        | 용도                     |
| --------------- | --------- | ------------------------ |
| `--success-500` | `#2E9B6B` | 성공 (브랜드와 동일)     |
| `--warn-100`    | `#FEF4E0` | 주의 배경                |
| `--warn-500`    | `#D99413` | 주의                     |
| `--danger-100`  | `#FDECEC` | 오류 배경                |
| `--danger-500`  | `#D64545` | **오류 / 5xx 일시 장애** |
| `--info-500`    | `#3B7DD8` | 정보                     |

**중요**: `--danger-*` 는 **일시 장애(5xx)** 전용이다. **데이터 부재(404)에는 쓰지 않는다.** 404는 `--fg-muted` + `--bg-subtle` 의 중립 톤으로 표현한다. (`docs/api-integration-guide.md` §3)

### 적합도 등급 색 (enum `code` 매핑)

서버가 `name`/`description` 을 내려주므로 **FE는 색만 매핑하고 문구는 서버 값을 쓴다.** 모르는 코드는 기본값으로 떨어진다.

| code        | 색            |
| ----------- | ------------- |
| `HIGH`      | `--brand-500` |
| `MEDIUM`    | `--warn-500`  |
| `LOW`       | `--fg-muted`  |
| (기타/미지) | `--fg-muted`  |

**색만으로 정보를 전달하지 않는다.** 등급은 색 + 텍스트(서버 `name`) + 아이콘을 함께 쓴다.

## 3. 타이포그래피

- 본문 폰트: **Pretendard** (한국어 가독성). `next/font/local` 로 subset 로드.
- 폴백: `-apple-system, BlinkMacSystemFont, "Malgun Gothic", sans-serif`
- 숫자 정렬이 필요한 곳(가격·거리·시간)은 `font-variant-numeric: tabular-nums`.

| 토큰      | size / line-height / weight | 용도                 |
| --------- | --------------------------- | -------------------- |
| `display` | 28 / 36 / 700               | 화면 대표 제목       |
| `title-1` | 22 / 30 / 700               | 섹션 제목            |
| `title-2` | 18 / 26 / 600               | 카드 제목            |
| `body-1`  | 16 / 24 / 400               | 본문                 |
| `body-2`  | 14 / 22 / 400               | 보조 본문, 목록 항목 |
| `caption` | 12 / 18 / 400               | 단위·기준·메타 정보  |
| `button`  | 16 / 24 / 600               | 버튼 라벨            |

- 모바일에서 본문 최소 14px. 12px은 캡션 전용.
- 긴 한국어 텍스트는 `word-break: keep-all` 로 어절 단위 줄바꿈한다.

## 4. Spacing 스케일

```text
4, 8, 12, 16, 20, 24, 32, 40, 48, 64
```

**스케일 밖 값을 쓰지 않는다.** Tailwind arbitrary value(`p-[13px]`)도 금지.

| 용도               | 값                                       |
| ------------------ | ---------------------------------------- |
| 아이콘-텍스트 간격 | 4, 8                                     |
| 카드 내부 패딩     | 16 (모바일), 20~24 (데스크톱)            |
| 요소 간 간격       | 12, 16                                   |
| 섹션 간 간격       | 32, 40                                   |
| 페이지 좌우 여백   | 16 (모바일), 24 (태블릿), 40+ (데스크톱) |

## 5. Radius

| 토큰            | 값     | 용도           |
| --------------- | ------ | -------------- |
| `--radius-sm`   | 6px    | 배지·칩        |
| `--radius-md`   | 10px   | 버튼·입력      |
| `--radius-lg`   | 16px   | 카드           |
| `--radius-xl`   | 24px   | 모달·바텀시트  |
| `--radius-full` | 9999px | 아바타·필터 칩 |

## 6. Shadow

여행 서비스이므로 그림자는 **가볍게** 쓴다. 3단계만 허용.

| 토큰          | 값                               | 용도                       |
| ------------- | -------------------------------- | -------------------------- |
| `--shadow-sm` | `0 1px 2px rgba(26,29,27,.06)`   | 카드                       |
| `--shadow-md` | `0 4px 12px rgba(26,29,27,.08)`  | 떠 있는 요소, 지도 위 카드 |
| `--shadow-lg` | `0 12px 32px rgba(26,29,27,.12)` | 모달·바텀시트              |

## 7. 브레이크포인트

| 이름    | 폭       | 비중                 |
| ------- | -------- | -------------------- |
| mobile  | ~767     | **1순위** (기준 375) |
| tablet  | 768~1023 | 2순위                |
| desktop | 1024~    | 3순위                |

- **모바일 우선으로 작성한다.** 데스크톱 스타일을 미디어 쿼리로 덧붙인다.
- 모바일 최소 터치 영역 **44×44px**.
- 모바일에서 **가로 스크롤이 생기면 버그**다. 넓은 콘텐츠(타임라인·표)는 자체 `overflow-x` 컨테이너로 감싼다.

## 8. 모션

- 기본 transition: `150ms ease-out` (색·투명도), `200ms ease-out` (변형·레이아웃)
- 바텀시트·모달: `250ms cubic-bezier(.2,.8,.2,1)`
- `prefers-reduced-motion: reduce` 를 존중해 변형 애니메이션을 끈다.
- **AI 일정 생성 대기**는 수초~수십초다. 무한 스피너 대신 진행 단계 표시를 쓴다.

## 9. 아이콘

- 선(line) 스타일, 굵기 1.5px, 24px 기본 / 20px 조밀 / 16px 인라인.
- **icon-only 버튼에는 반드시 `aria-label`.**
- 반려견 관련 아이콘은 과하게 귀엽게 가지 않는다 (제품 톤 §1).
