# 혼디가개 Design System

> **이 문서가 디자인 토큰의 단일 정본이다.** 색상·타이포·spacing·radius·shadow는 여기에만 정의한다.
> 상태: **2차 토큰 세트 — 컨셉 "데이터 신뢰형" 반영** (2026-08-27, 이슈 #48).
> 코드는 `src/styles/` 의 CSS 변수만 따라간다.
> **모든 대비비는 실측값이다.** 색을 바꿀 때는 다시 계산해 이 문서를 갱신한다.
> 적용 규칙과 공통 컴포넌트 목록은 `docs/styling-guide.md`.

## 1. 제품 톤

반려견과 함께하는 제주 여행. **따뜻하되 과장하지 않는다.**

시각 컨셉은 **데이터 신뢰형**이다 — **인터페이스의 채도를 낮추고 채도를 데이터에만 남긴다.** 표면(배경·테두리·회색)은 계측면처럼 중립적이고, 색이 붙는 곳은 측정값·등급·근거다.

- 사용자는 **여행 중 이동하면서** 본다 → 모바일 1순위, 큰 터치 영역, 짧은 문장.
- 정보 서비스가 아니라 **의사결정 지원** 서비스다 → 추천에는 항상 근거(XAI `reasons`)를 함께 보여준다.
- 마케팅 톤 금지. "최고의", "완벽한" 같은 표현을 쓰지 않는다.

### 용어 (고정)

| 사용             | 금지                 |
| ---------------- | -------------------- |
| 반려견           | 강아지, 애견, 멍멍이 |
| 여행 일정        | 여행 계획, 플랜      |
| 장소             | 스팟, 포인트         |
| 여행 적합도      | 여행 점수, 궁합      |
| 반려견 동반 가능 | 펫 프렌들리          |

## 2. 색상

제주의 자연(초록·바다)을 기본으로 하고, 반려견의 따뜻함을 accent로 둔다.

### 브랜드

| 토큰          | 값        | 용도                                  |
| ------------- | --------- | ------------------------------------- |
| `--brand-50`  | `#EFF8F3` | 배경 강조                             |
| `--brand-100` | `#D6ECE0` | 태그·칩 배경                          |
| `--brand-300` | `#7FC4A2` | 보조                                  |
| `--brand-500` | `#2E9B6B` | **주 브랜드** (버튼, 링크, 활성 상태) |
| `--brand-600` | `#237A54` | hover / 강조 텍스트                   |
| `--brand-700` | `#1A5C3F` | pressed                               |

### Accent (반려견·강조)

| 토큰           | 값        | 용도                    |
| -------------- | --------- | ----------------------- |
| `--accent-100` | `#FDEEE0` | **AI 표시** 배경        |
| `--accent-500` | `#E8843C` | **AI 표시** 아이콘·보더 |
| `--accent-600` | `#C86A28` | hover                   |

> **accent 는 "AI 가 생성·판단한 것" 표시 전용이다.** 장식 배지에 쓰지 않는다.
> 장식으로 쓰면 사용자가 AI 표시를 알아볼 근거가 사라진다.
> 현재 반려견 성향 배지(`pet-trait-badges.tsx`)가 이 색을 장식으로 쓰고 있어 **중립(`--bg-subtle`)으로 고쳐야 한다.**

### 중립

**초록 tint 를 제거했다.** 기존 회색은 전부 초록으로 기울어 있어 표면이 "자연물" 처럼 읽혔다.
중립으로 옮겨 데이터를 앞으로 낸다. 대비는 모두 개선됐다.

| 토큰              | 값        | 이전      | 용도                             | 흰 배경 대비 |
| ----------------- | --------- | --------- | -------------------------------- | ------------ |
| `--bg`            | `#FFFFFF` | 동일      | 페이지 배경                      | —            |
| `--bg-subtle`     | `#F5F6F8` | `#F7F8F7` | 섹션 배경                        | —            |
| `--bg-elevated`   | `#FFFFFF` | 동일      | 카드·모달                        | —            |
| `--border`        | `#E3E5EA` | `#E3E6E4` | 구분선·테두리                    | —            |
| `--border-strong` | `#C4C8D0` | `#C8CDC9` | 입력 필드                        | —            |
| `--fg`            | `#15181D` | `#1A1D1B` | 본문                             | **17.79:1**  |
| `--fg-muted`      | `#596069` | `#5F6762` | 보조 텍스트·캡션                 | **6.36:1**   |
| `--fg-subtle`     | `#878D96` | `#8A928C` | **placeholder·비활성·장식 전용** | 3.34:1       |
| `--fg-inverse`    | `#FFFFFF` | 동일      | 진한 배경 위 텍스트              | —            |

`--bg-subtle` 위 대비: `--fg` **16.45:1**, `--fg-muted` **5.88:1**. 둘 다 AA 통과.

> **`--fg-subtle` 을 읽는 텍스트에 쓰지 않는다.** 흰 배경 위 3.20:1 로 4.5:1 에 미달한다.
> 흰 배경 위 읽는 회색 텍스트는 **`--fg` 와 `--fg-muted` 2단계**뿐이다.

### 상태

**모든 텍스트 조합이 대비 4.5:1 이상을 만족한다** (배지는 12px 이라 예외가 없다).
`-500` 은 **흰 배경 위** 텍스트·아이콘·보더용, `-700` 은 **같은 계열 tint 배경 위** 텍스트용이다.

| 토큰            | 값        | 용도                                | 대비   |
| --------------- | --------- | ----------------------------------- | ------ |
| `--success-500` | `#2E9B6B` | 성공 (브랜드와 동일)                | —      |
| `--warn-100`    | `#FEF4E0` | 주의 배경                           | —      |
| `--warn-500`    | `#D99413` | 주의 아이콘·보더 (흰 배경)          | —      |
| `--warn-700`    | `#97670D` | **warn-100 위 텍스트**              | 4.51:1 |
| `--danger-100`  | `#FDECEC` | 오류 배경                           | —      |
| `--danger-500`  | `#D54040` | **일시 장애(5xx) 텍스트** (흰 배경) | 4.53:1 |
| `--danger-700`  | `#CE2D2D` | **danger-100 위 텍스트**            | 4.55:1 |
| `--info-100`    | `#F7F8F7` | 정보 배경                           | —      |
| `--info-500`    | `#3B7DD8` | 정보 아이콘·보더 (흰 배경)          | —      |
| `--info-700`    | `#2A70D2` | **info-100 위 텍스트**              | 4.54:1 |
| `--accent-700`  | `#A75921` | **accent-100 위 텍스트**            | 4.51:1 |

**중요**: `--danger-*` 는 **일시 장애(5xx) 전용**이다. **데이터 부재(404)에는 쓰지 않는다.**
404는 `--fg-muted` + `--bg-subtle` 의 중립 톤으로 표현한다. (`docs/api-integration-guide.md` §3)

> **tint 배경 위 텍스트에는 반드시 `-700` 을 쓴다.** `-500` 을 그대로 쓰면 대비가
> 2.35~3.86:1 로 떨어진다. 초기 구현이 실제로 그 상태였고 디자인 리뷰에서 발견됐다.

### 측정 스케일 `--metric-*` (신설)

적합도·산책 위험도 **등급 전용** 스케일이다. 상호작용 색(브랜드)과 의미 색(warn/danger)에서 분리한다.

**왜 분리하나.** 이전 세트는 `--brand-500` · `--success-500` · 적합도 `HIGH` 가 전부 같은 `#2E9B6B` 였다.
**주요 버튼과 "적합도 높음" 배지가 같은 색**이어서, 데이터가 주인공인 화면에서 "누를 것" 과 "측정값" 이 구분되지 않았다.
그리고 `MEDIUM → --warn-500` 은 **"보통 적합도" 와 "경고" 를 같은 신호로 만들었다.** 측정값은 경고가 아니다.

세 층 구조는 다른 색 계열과 같다 — `-100` tint 배경 / `-500` 흰 배경 위 바·아이콘 / `-700` 텍스트.

| 단계      | `-100` (tint 배경) | `-500` (바·아이콘)       | `-700` (텍스트)         |
| --------- | ------------------ | ------------------------ | ----------------------- |
| `HIGH`    | `#E4F0EA`          | `#1F7A55` (흰 위 5.29:1) | `#16563C` (tint 7.39:1) |
| `MEDIUM`  | `#FEF4E0`          | `#B0761A` (흰 위 3.85:1) | `#8A5F0F` (tint 5.16:1) |
| `LOW`     | `#EEF0F3`          | `#6B7280` (흰 위 4.83:1) | `#4B5563` (tint 6.62:1) |
| `UNKNOWN` | —                  | `#A8AEB8` (2.23:1)       | `--fg-muted` 를 쓴다    |

`-700` 의 흰 배경 대비: HIGH **8.64:1**, MEDIUM **5.64:1**, LOW **7.56:1**. 전부 AA 통과.

**규칙**

- **`--metric-mid-500`(`#B0761A`) 은 텍스트에 쓰지 않는다.** 흰 배경 3.85:1 로 본문 4.5:1 에 미달한다.
  3px 지표 바와 stroke 아이콘(비텍스트 UI 요소 3:1)에만 쓴다. **큰 숫자에는 예외가 있다** —
  18.66px 이상 bold 는 대형 텍스트로 3:1 이 기준이므로 22px/900 지표 숫자에는 허용된다.
- **`--metric-unknown`(`#A8AEB8`) 은 어떤 텍스트에도 쓰지 않는다.** 점선 테두리 전용이고,
  `UNKNOWN` 의 문구는 `--fg-muted` 로 쓴다. 혼잡도 `level` 이 `UNKNOWN` 으로 오는 경우가 실제로 있다.
- **`LOW` 에 danger 를 쓰지 않는다.** 적합도가 낮은 것은 오류가 아니다.
- **색만으로 정보를 전달하지 않는다.** 등급은 색 + 텍스트(서버 `name`) + 지표 바를 함께 쓴다.
  서버가 `name`/`description` 을 내려주므로 **FE는 색만 매핑하고 문구는 서버 값을 쓴다.**
- 모르는 code 는 `UNKNOWN` 으로 떨어진다.

### 브랜드 초록의 역할

`--brand-500` 은 이제 **상호작용 전용**이다 — 버튼, 링크, 활성 탭, 포커스 링.
등급 표시에 쓰지 않는다. `--success-500` 은 브랜드와 같은 값을 유지한다(성공은 상호작용의 결과다).

## 3. 타이포그래피

- 본문 폰트: **Pretendard Variable** (가변 축 `45~920`) — weight 100~900 전 구간과 중간값 사용 가능.
- 배포 방식: **dynamic subset** (`unicode-range` 분할, 조각 평균 31KB). 페이지에 실제 등장한 글자 범위만 내려받는다.
  근거와 대안 비교는 `docs/tooling-guide.md` §12.
- 폴백: `-apple-system, BlinkMacSystemFont, "Malgun Gothic", "Apple SD Gothic Neo", sans-serif`
- **지표·온도·거리·시각·날짜에는 `font-variant-numeric: tabular-nums` 를 반드시 쓴다.**
  "필요한 곳" 이 아니라 규칙이다 — 목록에서 자릿수가 흔들리면 값을 비교할 수 없다.
- **단위는 값보다 작고 흐리게 붙인다** (`caption` + `--fg-muted`). 값이 먼저 읽혀야 한다.
  단위 자체를 생략하지 않는다 — ℃ / km / % / 점 은 항상 표기한다.

### 3-1. Weight 9단계와 용도

가변 폰트라 9단계를 다 쓸 수 있다. **다만 한글은 라틴과 달리 얇은 쪽·굵은 쪽의 식별력이 급격히 떨어진다.**
획이 조밀해서 얇으면 뭉개지고, 이미 굵으면 더 굵어질 공간이 없다. 그래서 **최소 크기 제약**을 함께 둔다.

| weight         | Tailwind          | 용도                                 | 최소 크기                   |
| -------------- | ----------------- | ------------------------------------ | --------------------------- |
| 100 Thin       | `font-thin`       | 대형 디스플레이 텍스트의 장식적 표현 | **28px 이상**               |
| 200 ExtraLight | `font-extralight` | 대형 제목의 보조 표현                | **24px 이상**               |
| 300 Light      | `font-light`      | 긴 설명문, 인용                      | **16px 이상**               |
| 400 Regular    | `font-normal`     | **본문 기본**                        | 제한 없음                   |
| 500 Medium     | `font-medium`     | 라벨, 메타 정보, 필터 칩             | 제한 없음                   |
| 600 SemiBold   | `font-semibold`   | 카드 제목, 버튼 라벨                 | 제한 없음                   |
| 700 Bold       | `font-bold`       | 섹션 제목                            | 제한 없음                   |
| 800 ExtraBold  | `font-extrabold`  | 화면 대표 제목                       | **20px 이상**               |
| 900 Black      | `font-black`      | 숫자·지표 강조                       | **20px 이상, 1~2단어 이내** |

**규칙**

- **본문(16px 이하)에는 300 미만을 쓰지 않는다.** 모바일에서 읽히지 않는다.
- **800/900 은 짧은 텍스트에만.** 긴 한국어 문장에 쓰면 덩어리로 보인다.
- 700 과 800 을 같은 화면에서 위계로 쓰지 않는다. 한글에서 구분이 거의 안 된다. 위계가 더 필요하면 **크기**로 나눈다.
- 중간값(450, 550 등)은 쓰지 않는다. 가변 폰트라 가능하지만 9단계 밖으로 나가면 일관성이 무너진다.

### 3-2. 타이포 스케일

| 토큰      | size / line-height | 기본 weight | 용도                 |
| --------- | ------------------ | ----------- | -------------------- |
| `display` | 28 / 36            | **800**     | 화면 대표 제목       |
| `title-1` | 22 / 30            | **700**     | 섹션 제목            |
| `title-2` | 18 / 26            | **600**     | 카드 제목            |
| `body-1`  | 16 / 24            | **400**     | 본문                 |
| `body-2`  | 14 / 22            | **400**     | 보조 본문, 목록 항목 |
| `caption` | 12 / 18            | **500**     | 단위·기준·메타 정보  |
| `button`  | 16 / 24            | **600**     | 버튼 라벨            |

- 기본 weight를 벗어날 때는 §3-1 제약을 지킨다.
- 모바일에서 본문 최소 14px. 12px은 캡션 전용.
- 긴 한국어 텍스트는 `word-break: keep-all` 로 어절 단위 줄바꿈한다.

## 4. Spacing 스케일

```text
4, 8, 12, 16, 20, 24, 32, 40, 48, 64
```

**스케일 밖 값을 쓰지 않는다.** Tailwind arbitrary value(`p-[13px]`)도 금지.

| 용도               | 값                                       |
| ------------------ | ---------------------------------------- |
| 아이콘-텍스트 간격 | 4, 8                                     |
| 카드 내부 패딩     | 16 (모바일), 20~24 (데스크톱)            |
| 요소 간 간격       | 12, 16                                   |
| 섹션 간 간격       | 32, 40                                   |
| 페이지 좌우 여백   | 16 (모바일), 24 (태블릿), 40+ (데스크톱) |

## 5. Radius

둥근 모서리가 클수록 "말랑한 앱" 으로 읽힌다. 계측 도구의 정밀함을 위해 **한 단계 줄였다.**

| 토큰            | 값     | 이전 | 용도          |
| --------------- | ------ | ---- | ------------- |
| `--radius-sm`   | 4px    | 6px  | 배지·칩       |
| `--radius-md`   | 8px    | 10px | 버튼·입력     |
| `--radius-lg`   | 12px   | 16px | 카드          |
| `--radius-xl`   | 16px   | 24px | 모달·바텀시트 |
| `--radius-full` | 9999px | 동일 | 아바타        |

## 6. Shadow

**카드의 기본 표현은 `1px solid var(--border)` 다.** shadow 는 실제로 떠 있는 것에만 쓴다 —
지도 위 카드, 드롭다운, 모달·바텀시트. 평면 카드에 그림자를 얹으면 계측면의 평활함이 깨진다.

3단계만 허용한다.

| 토큰          | 값                               | 용도                    |
| ------------- | -------------------------------- | ----------------------- |
| `--shadow-sm` | `0 1px 2px rgba(21,24,29,.06)`   | (예비) 카드를 띄울 때만 |
| `--shadow-md` | `0 4px 12px rgba(21,24,29,.08)`  | 드롭다운, 지도 위 카드  |
| `--shadow-lg` | `0 12px 32px rgba(21,24,29,.12)` | 모달·바텀시트           |

## 7. 브레이크포인트

| 이름    | 폭       | 비중                 |
| ------- | -------- | -------------------- |
| mobile  | ~767     | **1순위** (기준 375) |
| tablet  | 768~1023 | 2순위                |
| desktop | 1024~    | 3순위                |

- **모바일 우선으로 작성한다.** 데스크톱 스타일을 미디어 쿼리로 덧붙인다.
- 모바일 최소 터치 영역 **44×44px**.
- 모바일에서 **가로 스크롤이 생기면 버그**다. 넓은 콘텐츠(타임라인·표)는 자체 `overflow-x` 컨테이너로 감싼다.

## 8. 모션

- 기본 transition: `150ms ease-out` (색·투명도), `200ms ease-out` (변형·레이아웃)
- 바텀시트·모달: `250ms cubic-bezier(.2,.8,.2,1)`
- `prefers-reduced-motion: reduce` 를 존중해 변형 애니메이션을 끈다.
- **AI 일정 생성 대기**는 수초~수십초다. 무한 스피너 대신 진행 단계 표시를 쓴다.

## 9. 아이콘

- 선(line) 스타일, 굵기 1.5px, 24px 기본 / 20px 조밀 / 16px 인라인.
- **icon-only 버튼에는 반드시 `aria-label`.**
- 반려견 관련 아이콘은 과하게 귀엽게 가지 않는다 (제품 톤 §1).
