# [기능명] 테스트 케이스

> 방식: vitest `environment: node` + `renderToStaticMarkup` 문자열 assertion (`docs/testing-guide.md`)
> 파일명은 `*.test.ts` (`.tsx` 아님)

## 1. 순수 로직 (우선순위 1)

| #   | 대상 함수 | 입력 | 기대 | 파일                    |
| --- | --------- | ---- | ---- | ----------------------- |
| 1   |           |      |      | `src/lib/.../*.test.ts` |

필수 확인 항목:

- [ ] `dataHeader.success` 판별
- [ ] `resultMessage` 정규화 (문자열 아닌 입력 포함)
- [ ] HTTP 상태 → 에러 종류 매핑 (404 / 401 / 400 / 5xx)
- [ ] 비동기 job: HTTP 200 + `status=FAILED` 를 **실패로** 판정
- [ ] `SliceResponse` 병합 + `hasNext` 종료
- [ ] 포맷 함수 (거리 / 기온 / 시간 / 금액 / 날짜)

## 2. 렌더 분기 (우선순위 2)

| #   | 상태           | 주장                                           | 파일 |
| --- | -------------- | ---------------------------------------------- | ---- |
| 1   | 404            | "다시 시도" 가 **없다** + `resultMessage` 노출 |      |
| 2   | 5xx            | "다시 시도" 가 **있다**                        |      |
| 3   | nullable 섹션  | 에러가 아니라 **숨김**                         |      |
