# [BE] feat: 중기예보 연동으로 여행 적합도 예보 커버리지 확대

> GitHub 이슈 초안. 아래 `## 어떤 기능인가요?` 부터가 이슈 본문이다.
>
> - 라벨: `backend-tour-service`, `backend-core`, `backend-plan-service`
> - 브랜치: `feature/be/<이슈번호>-mid-term-forecast`
> - 예상 규모: 20~25파일
>
> **아래 본문의 커버리지 숫자(D+0~D+2, "3일")는 작성 시점의 문서 기준이다.**
> 실호출로 확인하니 단기예보는 5일치였다. 정정한 내용은 문서 끝의 "실호출 검증 결과" 절에 있다.
> 틀린 전제를 지우지 않고 남긴 이유는, 이 초안이 "그때 무엇을 몰랐는지"의 기록이기도 해서다.

## 어떤 기능인가요? ✏

- 기상청 중기예보(`MidFcstInfoService`)를 붙여 예보 커버리지를 **3일에서 11일로** 늘린다
- 지금은 단기예보(D+0~D+2)만 있어서 3일 밖 날짜를 물으면 `score = null` + `INSUFFICIENT` +
  "예보 범위 밖"만 돌려준다. **여행 계획 서비스에서는 이쪽이 예외가 아니라 기본 경로다** —
  다음 주말, 다음 달 여행을 짜는 사용자에게 적합도가 아무 말도 못 하고 있다

## 참고할만한 자료(선택)

### 단기예보를 그대로 복사하면 안 된다

| | 단기예보 (구현됨) | 중기예보 (추가) |
| --- | --- | --- |
| 위치 지정 | 격자 `nx`, `ny` | **예보구역 `regId`** |
| 발표 | 1일 8회 (3시간 간격) | **1일 2회 (06, 18시)** |
| 시간 해상도 | 1시간 단위 | **오전/오후만** |
| 커버리지 | D+0 ~ D+2 | **D+3 ~ D+10** |
| 오퍼레이션 | `getVilageFcst` 하나 | **둘을 조인해야 하루가 완성** |

`KmaGrid`(격자 변환)가 이 경로에는 쓰이지 않는다.

### 기능별로 영향이 갈린다

- **여행 적합도 — 된다.** 기온·강수확률·하늘상태가 있어 판정이 성립한다. 단 **습도와 풍속이
  없어** 열지수 보정과 강풍 감점이 빠진다. 근거가 줄어든 것을 응답에 드러내야 한다
- **산책 위험도 — 안 된다.** 노면(아스팔트) 온도는 `기온 + 일사(날짜·시각·위도) x 하늘상태 x 바람`
  으로 계산하는데 중기예보에는
  **시각별 데이터가 없다.** "오전/오후"로는 14시 아스팔트를 판정할 수 없다. 억지로 값을 내면
  없는 근거를 지어내는 것이라 3일 밖은 계속 `UNKNOWN` 이 맞다

이 구분 자체가 설계다. 지금 `WalkSafetyReasonCode.FORECAST_OUT_OF_RANGE` 문구가 "단기예보가
닿지 않는 시각"인데, 중기예보를 붙이면 이유가 "예보에 시각별 정보가 없어서"로 바뀐다.

### 응답에 출처를 드러낸다

같은 `score = 72` 라도 단기예보에서 나온 것과 중기예보에서 나온 것은 신뢰도가 다르다.
사용자가 그걸 알아야 한다. 기존 `weatherApplied` / `congestionApplied` 플래그와 같은 이유다 —
근거의 성질을 감추지 않는다.

### 경계 규칙

단기예보는 D+2 까지 확실하고 발표 회차에 따라 D+3 일부가 걸치기도 한다.
**겹치는 날짜는 단기예보를 우선한다** — 더 정확하고 시각별 데이터가 있다.
이 규칙은 프로세서 한 곳에만 둔다.

### 쿼터는 거의 안 든다

지역 단위라 격자보다 호출이 두 자릿수 적다. 제주 한 지역이면 `2 오퍼레이션 x 1일 2회 = 4콜/일`.

### 실호출 검증 결과 (2026-08-27)

키는 관광공사 키와 동일하다. 아래는 직접 호출해 확인한 내용이다.

- **예보구역 코드 셋 다 유효** — 육상 `11G00000`, 기온 `11G00201`(제주)/`11G00401`(서귀포).
  같은 회차에서 최고기온이 제주 32도 / 서귀포 31도로 갈려 지점 분리가 실제로 의미가 있다
- **필드명 확인** — `rnSt4Am`/`wf4Am` 형태. 7일차까지 `Am`/`Pm`, 8일차부터 접미사 없음
- **첫 일차가 회차마다 다름** — 06시 회차는 4일차부터, 18시 회차는 5일차부터.
  발표일이 하루 차이라 실제 첫 예보일은 같다
- **날씨 문장** — `맑음`, `구름많음`, `흐림`, `흐리고 비` 확인

### 예상하지 못했던 발견 둘

1. **단기예보는 3일이 아니라 5일이다.** 문서·주석·Swagger 문구를 전부 정정했다
2. **단기예보 마지막 날은 자정 한 시각뿐이다.** 하루로 접으면 "최고기온 = 자정 기온"이 되어
   근거 없는 점수가 조용히 나간다. `DailyWeather.hasDaySummary` 로 온전함을 따지고,
   온전하지 않으면 중기예보를 쓰도록 병합 규칙을 고쳤다

자세한 실측값은 `data-api-analysis.md` §6-2 에 남겼다.
