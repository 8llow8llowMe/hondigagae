# 혼디가개 (hondigagae)

관광 데이터를 기반으로 반려견 맞춤 여행을 설계하고, 최적의 여행 의사결정을 지원하는 AI 기반 스마트 관광 서비스.
(2026 관광데이터 활용 공모전)

## 서비스 개요

혼디가개는 반려견과 함께하는 여행에서 발생하는 다양한 고민을 해결하기 위해 기획된 AI 기반 맞춤형 여행 설계 서비스입니다. 사용자는 여행 일정과 반려견의 특성을 입력하는 것만으로, 관광 데이터를 기반으로 최적화된 여행 코스를 자동으로 추천받을 수 있습니다.

기존의 관광 서비스가 단순한 정보 제공에 그쳤다면, 혼디가개는 한 단계 더 나아가 여행 일정을 직접 설계하고, 상황에 맞게 유연하게 조정하는 '의사결정 지원형 서비스'를 지향합니다. 특히 반려견의 활동량, 성격, 환경 민감도와 같은 요소를 고려하여 사람이 아닌 반려견 중심의 여행 경험을 제공합니다.

또한 제주 지역의 관광 특성과 이동 환경을 반영하여 실질적으로 활용 가능한 여행 코스를 제공하며, 날씨와 혼잡도 데이터를 결합한 여행 적합도 분석 기능을 통해 사용자에게 더욱 안전하고 효율적인 여행 경험을 제공합니다.

## AI 기능 후보

> **아직 개발 착수 전이며, 아래 10개는 기능 후보 풀이다.**
> 전부 구현하기에는 범위가 크므로, 이 중 **핵심 기능 몇 개만 의사결정을 거쳐 선정**해 개발한다.
> 선정 기준: 공모전 차별화 효과, 구현 난이도, 데이터 확보 가능성, 개발 기간.
> 선정 결과가 확정되면 이 표에 선정/보류 상태를 반영한다.

| # | 후보 기능 | 설명 | 상태 |
|---|------|------|------|
| 1 | AI 여행 플래너 | 여행 조건 + 반려견 특성 + 예산 입력 → 일정 자동 생성 | 후보 |
| 2 | 일정 수정 AI | 자연어로 일정 변경 ("카페 말고 다른 곳 가고 싶어") | 후보 |
| 3 | AI 여행 상담사 | 반려견 여행 관련 대화형 상담 | 후보 |
| 4 | 여행 적합도 분석 | 날씨·혼잡도·반려견 조건 기반 점수 + 이유 제공 | 후보 |
| 5 | 반려견 성향 분석 | 여행 이력 학습 → 선호 장소/활동 프로파일링 | 후보 |
| 6 | 여행 후기 자동 작성 | 사진 업로드 → AI 후기 생성, SNS 공유 | 후보 |
| 7 | AI 여행 비서 | 여행 중 실시간 대화형 일정 변경·추천 | 후보 |
| 8 | 긴급 상황 도우미 | 현재 위치 기준 24시 동물병원 안내 | 후보 |
| 9 | 여행 스타일 학습 | 사용자 여행 기록 기반 개인화 | 후보 |
| 10 | 설명 가능한 AI (XAI) | 추천 이유를 데이터 근거와 함께 제시 | 후보 |

## 활용 데이터

- **국문 관광정보 서비스 GW API** — 관광지, 음식점, 숙박 기본 데이터
- **반려동물 동반여행 API** — 반려견 출입 가능 여부, 이용 조건
- **관광지별 연관 관광지 API** — 관광지 간 연결성 분석 (코스 자동 생성)
- **두루누비 API** — 산책·레저 코스
- **관광지 집중률 방문자 추이 예측 API / 관광빅데이터 정보 서비스 API** — 혼잡도, 방문자 수
- **기상청 지상 관측자료 조회 API** — 기온, 강수, 바람 (반려견 활동 적합도)
- **카카오 로그인·지도 API** — 사용자 인증, 위치 기반 시각화, 경로 안내 (향후 카카오 메시지 API 연계)
